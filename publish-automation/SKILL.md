# 发布自动化（publish-automation）

## 一、发布前（材料由 publish-pack 产出）

1. 核对发布材料：标题变体（平台口味）、话题标签、AI 自主声明、封面图、简介；
2. **平台硬门槛核对**（发布前最后一关）：
   - 时长/分辨率/格式符合平台与赛事官方规则（**以赛事官方文档为准，不写死平台名**）；
   - 话题标签正确（赛事指定话题，不加其他平台话题）；
   - AI 声明已加；
   - 参赛：手机号与平台注册一致、作品不可私密不可删除。

## 二、发布动作（三档）

| 档位 | 场景 | 做法 |
|---|---|---|
| 手动 | 首次发布/账号敏感 | 生成"发布操作清单"（步骤+字段值），用户照贴 |
| 半自动 | 账号已登录且素材本地 | browser-use-automation 打开平台发布页 → 填标题/话题/上传成片 → 停在"确认发布"前让用户点 |
| 全自动 | 已录制过 RPA | browser-record-replay 录制一次发布流程 → 后续复用（注意：平台风控可能要求验证码，遇验证码停手交回用户） |

## 三、参赛投稿（叠加动作）

1. 抖音发布完成 → 平台站内【赛事】专区【立即投稿】；
2. 填写邀约人信息（抖音昵称，无则留空）；
3. 记录投稿时间与投稿编号（前 100 名合规投稿有积分激励，尽早投）；
4. **留存工作流证据**：平台后台生成记录/工作流截图（获奖核验必需）。

## 四、发布后状态记录

```markdown
## 发布记录
- 成片：{标题}，时长 {s}，平台 {平台}
- 抖音链接/ID：…
- 投稿时间：…，投稿编号：…
- 话题：…，AI声明：✓
- 工作流证据：{截图/记录位置}
- 播放数据起点：{发布日播放量}
```

## 五、门禁

- 发布前：材料齐全+硬门槛全过+话题/AI 声明正确；
- 发布中：自动化遇登录墙/验证码立即交回用户，不硬闯；
- 发布后：记录已写、参赛投稿已提交、工作流证据已留存。

## 六、与总控衔接

挂在 `video-command-center` 第 10 环（发布）：publish-pack 出材料 → 本技能做发布动作与投稿 → 数据复盘（post-publish-review）。

## 七、强化升级（蒸馏自开源发布工具链，详见 `references/publish-automation-open-source.md`）

1. **受控六段流水线**（Moimobi）：内容摄取→平台适配→审批→发布→检查→记录——发布是流水线不是单脚本；
2. **发布前复核清单**（Repostit）：caption/title/cover/CTA/目标账号/权限 六项逐项打勾，任何一项不确认不发；
3. **发布后检查关卡**：核链接可访问、标签/AI 声明正确、无发布事故；
4. **发布记录自动落盘**：成片+链接+投稿编号+证据位置（发布后必写，不靠记忆）；
5. **自动化边界**（video-uploader/auto-publisher 共同经验）：登录墙/验证码立即交回用户，cookie 复用+手动登录兜底，平台参数差异表（如标签上限）先查再发。
