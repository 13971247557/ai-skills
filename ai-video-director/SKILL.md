# 全流程总控（ai-video-director）

## 定位

**导演不亲自拍每一镜，而是确保每一镜按剧本拍完。** 本技能是成片链的"总控层"：负责需求解析、技能路由、环节门禁与交付把关；不重复各技能的操作细节（细节在各自 SKILL.md），只负责"顺序、门禁、验收"。

**【2026-10 精链收敛原则】** 用户最高诉求："什么都会但什么都不精，我要那种可以精的。"
因此本总控只硬承诺**精链六环**，每环一个可执行硬门禁；其余能力一律降级为"可选旁支"，默认不启用，用户点名才上。**一镜不过门禁，整镜重抽，绝不带病进合成。**

## 技能链（导演的剧组）

### 精链主流程（六环 · 每环一个硬门禁，不过不进下一环）

| 环 | 环节 | 技能 | 硬门禁（不过不进下一环） |
|---|---|---|---|
| ① | 素材图资产 | `doubao-creative-design` + `shot-asset-manager` | **角色多视图锚点 + 场景多景别锚点生成后，用户逐张审核确认（不可跳过）** |
| ② | 论文级提示词 | `ai-short-video` + `prompt-engineering` + `ai-short-drama-pipeline/references/prompt-craft-mindset.md`（手搓提示词工匠：token 前15词主体/句尾15-20字光线镜头/6节拍动作链/风格块） | **三层提示词齐备且 `prompt_check.py --domain video` 退出码 0**（必含时长/运镜词；三层不得混写） |
| ③ | 图生视频 | `ark-video-pipeline` / `no-watermark-channels` | 锚点图作首帧、一镜一动作；**小样 Draft 先过构图动作**，才出正式版 |
| ④ | 一致性锁定 | `shot-asset-manager` | **逐镜抽帧对照锚点图，身份块逐字比对零差错**，偏移立即重抽 |
| ⑤ | 每镜质检 | `shot-asset-manager`（frame_extract）；失败返工走 `ai-short-drama-pipeline/references/prompt-optimizer-models.md`（返工诊断闭环：失败模式→归因→一次只改1-2变量→复评） | **抽帧五项检查全过（主体/手/口型/构图/运镜）；任一镜不过禁止进合成**（量化见 pipeline.md） |
| ⑥ | 剪辑交付 | `video-edit-pipeline` | 转场/节奏/三层混音/色彩/去塑料感过 + **交付前完整性检查八项** |

### 可选旁支（默认不启用，用户明确点名才上；不进主流程承诺）

| 旁支 | 技能 | 何时才启用 |
|---|---|---|
| 花字/片头片尾/文字卡点卡片 | `hyperframes-html-video` | 用户要"复杂动效包装/逐词弹花字/动态片头"时 |
| 卡点吸附拍点 | `beat-sync` | 用户明确要"踩点剪辑/节拍切换"时 |
| 口型修复 | `lip-sync` | **默认用"对白改内心独白旁白"规避**（见决策分支③），仅用户坚持要真人嘴型对白时 |
| BGM 重编曲 | `bgm-remaster` | 用户说"歌词好但伴奏差/想换编曲"时 |
| 环境音效垫底 | `sfx-layer` | 复杂氛围片；普通短片用剪辑自带环境声即可 |
| 发布包打包 | `publish-pack` | 用户要"一键多平台发布材料"时 |

## 主流程（精链六环 · 导演执行清单）

**环① 素材图资产（走 shot-asset-manager）**
- 出两类锚点：**角色多视图锚点**（正面/侧面/表情，走 `character-refs`）+ **场景多景别锚点**（关键场景底图）。
- 从角色提示词里固化一段**身份块**（年龄/发型/服装颜色款式/标志道具），全片逐字复用。
- **硬门禁：单独交付用户逐张审核，用户确认前不生成任何镜头。**

**环② 论文级提示词（走 prompt-engineering 三层体系）**
- 三层分开写，**禁止把三层混在一句 prompt 里**（来源：创作者拆解资产1）：
  1. **首帧长模板**（150–250 字）→ 喂生图模型出首帧：堆风格锚点/角色/环境/光线/画质。
  2. **分镜表** → 喂 `ai-short-video`：每镜一行，含"每镜三要素"（运镜 / 动作变化链 / 环境光影）。
  3. **每镜执行短提示词**（20–60 字）→ 喂图生视频模型：`时长X秒。[景别][运镜]，[主体][动作变化链]，[环境/光影]，[画质约束]`，**一镜只一个主动作**。
- **硬门禁：** `python3 prompt-engineering/scripts/prompt_check.py --domain video --anchor "<运镜词>" --prompt "<短提示词>"`，退出码 0 才放行（必须含时长 + 运镜词）。三层模板见 `prompt-engineering/references/video.md`。

**环③ 图生视频（锚点图作首帧，一镜一动作）**
- 用环①锚点图作首帧/参考图（i2v），按环②短提示词生成。
- **先出小样 Draft 验证构图与动作，过了再出正式版。**
- **硬门禁：** 无崩坏 + 无不可接受水印；渠道见 `no-watermark-channels`。

**环④ 一致性锁定（同一锚点资产）**
- 逐镜抽帧对照环①锚点图，**身份块逐字比对**（服装颜色/款式/发型/道具一字不差）。
- **硬门禁：** 任一镜身份块偏移 → 立即重抽；全部通过才进环⑤。

**环⑤ 每镜质检（本次新增硬门禁 · 量化）**
- 生成后立刻抽帧：`python3 shot-asset-manager/scripts/frame_extract.py --video <shot>.mp4 --out ./qa --times <25%,50%,75%对应秒数>`（5 秒镜抽 3 帧；≥10 秒镜用 `--all --fps 0.5` 每秒 1 帧）。
- 五项检查 + 判定标准 + 重抽规则见 `references/pipeline.md`「每镜质检硬门禁」。
- **硬门禁：任一镜五项不过 = 禁止进环⑥合成。不合格固定锚点重抽（决策分支①），禁止带病进合成。**

**环⑥ 剪辑交付（转场/节奏/混音/色彩/去塑料感）**
- 转场优先伪长镜头三件套：形状匹配 → 物体遮挡 → 新事件遮盖（声音层 J-Cut 预置）。
- 节奏（3s 情绪冲击/15s 剧情变化）、三层混音（人声最前/BGM 压 6–10dB/环境音垫底）、统一 LUT 色彩、**去 AI 塑料感三件套**（胶片颗粒 noise + 微妙色偏 colorbalance + 轻微对比度 eq）。
- **硬门禁：** 交付前完整性检查八项（见 `references/pipeline.md`）。

## 决策分支（遇到 X → 执行 Y，硬规则，不许自由发挥）

**① 局部编辑 vs 整段重跑**（来源：爆款拆解A 资产D《被贬》）
- IF 人物姿态 + 构图 + 机位 + 光线都 OK，仅局部材质/细节出问题（如垂帘太轻、地面纹理脏）
  → **执行局部编辑，只改出错区域，保留人物状态/机位/光线；禁止整段重跑。**
- IF 整体构图/景别就不对 → **整段重跑**，改提示词里的景别与构图描述。

**② 多模型分工**（来源：爆款拆解A 资产B《牌子》DiDi_OK）
| 镜头需求 | 首选模型 | 备选 |
|---|---|---|
| 人物对话/嘴型同步 | Veo | Seedance 2.5 |
| 大推拉/高张力运镜 | 可灵 | Runway |
| 物理动作/摔倒/碰撞 | Runway | Seedance |
| 通用稳定、后续要手动后期合成 | Seedance 2.0/2.5（720P 够用） | Nana Banana |
| 4K 静帧/资产图 | Nana Banana | Midjourney |

**③ 对白出戏 → 内心独白旁白**（来源：创作者拆解 B 线资产A8）
- 遇到剧情短片需求 → **默认主线无对白，对白改内心独白旁白**，情感靠画面 + BGM 扛。理由：AI 中文对白口型/配音必出戏（多作验证）。仅用户坚持要真人嘴型对白时才启旁支 `lip-sync`。

**④ 抽卡批次策略**（来源：爆款拆解A 资产F《牌子》）
- 一镜**4 连抽并行**（同一短提示词一次性提交 4 个任务），全部跑完统一筛 80 分以上，不盯进度条。
- 普通镜 3–5 次即可；**关键镜（一镜到底/高潮）可抽数百~3000 次**；每轮重抽只改 1–2 个变量。

## 硬规则

- **出片质量第一**：任何环节质量不达标 → 回该环节重做，不带着问题往下走；
- **用户提示词原样采用**：用户给的生成提示词不增删不改写（ark-video-pipeline 规则）；
- **用户审核关卡不跳过**：设定图未确认不生成镜头；素材图先给用户看（成片前先看素材）；
- **交付前必过完整性检查**：三项（字幕无重叠/可播/对齐）为交付底线；
- **每个阶段只做本阶段的事**：不提前、不返工、按门禁顺序执行。

## 执行模式

- **整条执行**：用户要求完整出片 → 按精链六环 ①→⑥ 逐步执行，每环完成即汇报进度；
- **从中间切入**：用户已有分镜/素材 → 从对应环开始，前面环节跳过；
- **单环节求助**：用户只要写文案/配音/选BGM 等 → 直接走对应技能，不经本总控（本技能描述已排除）。

**REQUIRED SUB-SKILL:** 导演的剧组——

*精链主流程（默认全走）：*
- `ai-short-video`：选题/文案/分镜/每镜三要素（产出分镜表）；
- `prompt-engineering`：三层提示词（首帧长模板/分镜表/逐镜短模板）+ prompt_check 门禁；
- `shot-asset-manager`：素材图资产生成→用户审核硬关卡→身份块锁定→每镜抽帧质检→一致性校验；
- `ark-video-pipeline`：图生/文生视频执行生成（忠实提示词）；
- `no-watermark-channels`：免费无水印渠道路由与额度监控；
- `video-edit-pipeline`：配音+字幕+BGM+合成+交付前完整性检查。

*可选旁支（默认不启用，用户点名才上）：*
- `bgm-selection`：按情绪选BGM并验证BPM；`bgm-remaster`：歌词好伴奏差时重编曲；
- `beat-sync`（卡点）、`lip-sync`（口型，默认用旁白规避）、`sfx-layer`（环境音效）、`publish-pack`（发布包）；
- `hyperframes-html-video`：HTML 出片通道，需复杂花字/片头片尾/文字卡点卡片时产出无水印动画 mp4 层。
