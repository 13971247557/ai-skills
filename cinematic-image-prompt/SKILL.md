# 电影感出图提示词框架（cinematic-image-prompt）

> 蒸馏来源（2026-10-20）：抖音"θ的图文"《AI出图没电影感？这个Skill直接救活》+ 相关博主方法论（小彻"告别塑料感两步"、RoboNeo 三技巧、调色三技巧、导演 Skill 三步法、Seedance 2.5 结构化提示词）。

## 一、六维提示词框架（生图/分镜通用，逐槽填具体词）

写电影感提示词 = **[构图] + [光影] + [角色] + [氛围] + [材质] + [镜头]**，六维全填，不写形容词堆砌：

1. **构图**：黄金比例/三分法/引导线/留白方向/主体位置。例："主体居右下三分线，左侧留大面积负空间，视线引导线由前景桌面斜向人物"
2. **光影**：光源方向+软硬+明暗层次。例："左侧 45° 硬侧光，亮部过曝压暗部，人物半张脸陷入阴影，明暗分明有层次"（**电影光=明暗分明，不是大平光**）
3. **角色**：身份块（外貌/服装/年龄）+ 表演状态。例："50岁档案管理员，深蓝旧工装，双手捧卷宗，目光低垂专注"
4. **氛围**：空气/时间/情绪。例："傍晚档案室，冷白日光灯与窗外暮色对冲，纸尘在光束中浮动"
5. **材质**：每件物体带表面处理。例："老式铁皮柜哑光漆面有划痕锈迹，牛皮纸卷宗纤维质感，木桌面磨损"
6. **镜头**：焦段+机位高度+景深。例："35mm，人眼高度，浅景深，前景桌角虚化"

**一句话版**：把六维压缩成一句话也可以出片（如"午后的档案室，逆光里浮着纸尘，穿深蓝工装的老人低头理卷宗，35mm 浅景深"）——但逐维展开更稳。

## 二、一句话出图工作流（Skill 用法）

1. 让 AI 按六维框架，根据你的主题/用途输出 **N 个电影感提示词**（带模板可直贴）
2. 挑一个 → 生图（选模型+比例，一次多张挑一张）
3. **把出的图丢回给 AI** → 让它写一段**图生视频提示词**（画面动起来：运镜+动作+氛围延续）
4. 图+视频提示词 → 生成视频

**分层描述镜头感**（治"单薄/塑料感"）：
- 描述前景（强调虚化）→ 聚焦主体（清晰）→ 背景（朦胧景深）
- 本质：**你不是在画画，而是在摆镜头**

## 三、电影质感技巧库（去塑料感）

1. **前景遮挡=真实机位感**：画面要有"镜头躲在某处拍"的感觉——前景加虚焦物（门框/桌角/帘边/光点），中景主体，背景深度。**没有前景遮挡的画面=塑料感第一元凶**
2. **空气颗粒=氛围厚度**：光线里的尘埃/薄雾/水汽/雪花让光影可见。太空/室内/夜景加"漂浮微粒、光线散射"，画面立刻有呼吸感
3. **631 配色法则**：主色 60% / 配色 30% / 辅助色 10%。抽卡时颜色尽量简单，后期 HSL 把相近色色相贴近，画面统一
4. **人像肤质提升**：人物肤质决定真实感。有肤质提升功能的工具直接用；提示词可加"自然皮肤纹理、可见毛孔绒毛、无磨皮感"
5. **统一色系**：全片一种色调语言（本项目冷白偏青），明暗分明；后期 log 色轮微调中间调/高光靠近主色
6. **运镜精准**：动态镜头用画笔标记运镜轨迹或预设，比纯文字描述运镜更精准；固定镜头写"no camera movement"
7. **后期调色三件**：HSL 统一色相 → log 色轮增对比（加高光减阴影）→ 颗粒/锐度/超分提质感；色彩克隆批量统一素材色调

## 四、结构化提示词（Seedance 2.5 适配，视频侧）

把原始提示词按 SD2.5 更适配的结构重排：**主体+动作 → 镜头语言（焦段/角度/运动）→ 光影氛围 → 画面质感 → 负面词**。没提示词时可"拉片"拆参考视频（镜头语言/构图/运动/视觉风格），**提取亮点转原创，不复制**。出片后只改不满意的片段（局部重拍），不整条重跑。

## 门禁

- 生图前六维框架过一遍，缺维不调用
- 出图先查：有无前景虚化层？有无明暗层次？有无空气颗粒？无则重写
- 图生视频前：先让 AI 出衔接提示词，画面风格必须延续原图
