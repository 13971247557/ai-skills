# elevenlabs-v4-voice（ElevenLabs v4 语音模型）

> 来源（2026-10-19 蒸馏）：抖音 Higgsfield.AI 发布的 ElevenLabs v4 演示 + ElevenAgents 智能体语音 + 商业分析（估值110亿美金、文字转语音是艺术）+ 开源替代 VoiceStudio。

## 一、v4 / v4turbo 能力边界

| 能力 | 说明 |
|---|---|
| 声音克隆 | **10秒录音**即可克隆声音（普通用户30秒音频生成专属语音模型） |
| 语言覆盖 | 70+ 语言扩到 **90+**，普通话/粤语提升最明显 |
| 情绪控制 | **一句自然语言提示**即可演出情绪、语速和笑声（不用参数堆叠） |
| 音色保持 | 换语言时**保持同一人的音色**，只带上本地口音（通用翻译器愿景） |
| v4turbo | 首字延迟约 **150ms**，专给实时语音对话；官方称语音对战榜第一 |
| ElevenAgents | 智能体实时语音：中位数推理延迟约 **100ms**，情感表现力更强+长通话稳定，可应对医疗/金融敏感场景 |

## 二、配音情绪提示写法（自然语言驱动）

ElevenLabs v4 的核心：**用自然语言描述"怎么演"，不用专业参数**。

示例写法：
```
用低沉压抑、语速缓慢（每3-3.5字停顿一次）的老年女性声音，平静中带着克制的心虚，说出："……陈映雪。我叫陈映雪。"
```
- 先给**声音角色**（年龄/性别/音色质感）
- 再给**表演状态**（情绪/语速/停顿/呼吸感）
- 最后给**台词原文**

## 三、应用映射（《她的名字》配音规格）

剧本配音规格可直接转成 v4 自然语言提示：
- 映雪（60岁返聘档案员）：低沉压抑 3-3.5字/秒，低声、呼吸感、停顿多 → "低沉压抑的老年女声，语速极慢，每句话末尾停顿半拍，像怕被人听见"
- 旁白金句：2.5-3字/秒逐字，庄重克制
- 其他角色：正常4字/秒
- 深夜电话戏：低弦乐垫底+压抑女声
