# movie-realism-edit（电影真实感与镜头衔接）

> 蒸馏来源（2026-10-19 调研）：北京电影学院《写实主义AI电影创作与理论研究》（镜头调度体系）、WJEC/电影语言教材（摄影机与光）、Adobe/Backstage/FilmVision（J-L-Match cut 剪辑）、QuestStudio/Elser/DeSight（AI 视频去 AI 感）、RenderIO/Frank Houbre（运动模糊与物理）。

## 一、电影质感六要素（每镜自检）

1. **光**：光是电影存在的基本要素。画面亮度/反差必须符合场景空间环境与全片主题基调；用光突出主体造型、营造气氛、帮助构图。本项目=80-90年代机关档案室冷白日光灯+胶片颗粒（低密度高细节）。
2. **连续运动**：电影感的本质=连续运动。每个镜头注入运动（推/拉/摇/移/跟/手持漂移），禁止死画面；构图承载电影信息，避免大面积空洞。
3. **镜头调度像真人摄影**（北电系统）：长镜头/斯坦尼康/手持/轨道/升格/航拍按剧情需要选，模拟专业摄影调度；AI 镜头太完美（无重量滑动、无动机旋转）=塑料感。
4. **景深层次**：前/中/背景分离（前景遮挡/背景虚化/纵深构图），像真实摄影机焦距拍出。
5. **色彩与反差**：统一色温（本项目冷白 5000K 偏青锚）、反差克制、胶片色调，不炫技调色。
6. **声音**：配音/BGM/环境三层混音（1.0/0.4/0.18），环境声贴合空间（sfx-layer 规则），拟音与画面动作一一对应。

## 二、去AI感五法（逐镜强制）

1. **一镜一动规则（One Move + One Action）**：一次镜头运动 + 一个主体动作。例：慢推 + 眨一次眼；手持漂移 + 轻转头；固定机位 + 走两步。动作时间用"拍子/计数"描述（如"第2秒眨眼一次"），禁止一镜塞多个大动作（AI 会 morph）。
2. **像人运镜**：用简单语言限定："慢推""轻微手持漂移""固定三脚架镜头""平缓跟拍"；禁止"丝滑环绕""无动机旋转"等 AI 味运镜。
3. **运动模糊适中**：24fps 快动作无模糊会"频闪"，过糊成"涂抹"；中等快门感（快门 180° 等效）让观者能跟随主体。
4. **自然瑕疵层**：成片加 2-3% 胶片颗粒 + 环境底噪层 + 轻微压缩感 = 去除"干净得假"的 AI 感。
5. **时序一致性锁词**：同一场景相邻镜之间，全局设定词（光线/材质/机位/服装）必须原词复用，禁止改动多个提示词（改动=一致性崩坏/穿帮）。

## 三、镜头衔接四手法（分镜与剪辑阶段使用）

| 手法 | 做法 | 效果 | 本项目用法示例 |
|---|---|---|---|
| **J-cut（声音先入）** | 下一场景的声音先于画面出现 0.5-1s | 平滑预告转场、牵引观众 | 场九落笔前，心跳声先入→再切特写 |
| **L-cut（声音延续）** | 上一场景声音延续到下一镜画面 | 贴近人的自然反应、声画错位衔接 | 抽卷动作的纸张声延续到柜内特写 |
| **Match cut（匹配剪辑）** | 两镜视觉相似（形状/运动/色彩/构图）硬切 | 无缝+主题关联 | 卷宗入档→同构切入 2000 年同一动作 |
| **动作衔接** | 上个镜头动作未完处切入下镜（同一动作连续性） | 掩盖剪辑点 | 插入钥匙动作跨镜连续 |

- **禁止** Jump Cut（同主体跳切=断裂感）与无动机转场；
- **180° 轴线规则**：对话/动作轴线两侧不得越轴互切（越轴=方向感错乱）。

## 四、本项目 84 镜出片逐镜执行清单（出片阶段门禁）

每个镜头出片前过以下清单，任一项不满足→调整提示词或重出：

- [ ] 一镜一动：镜头运动 ≤1 种、主体动作 ≤1 个
- [ ] 运动描述用简单语言（推/摇/手持漂移/固定/跟），禁"丝滑环绕"
- [ ] 全局设定词与本镜所属场景锚点一致（光线/材质/机位），跨镜复用原词
- [ ] 冷白 5000K 偏青色温锚重申（反暖指令），胶片颗粒与低密度细节
- [ ] 衔接点设计：与上/下镜的衔接手法已定（J/L/Match/动作），声音先入/延续已标注
- [ ] 无越轴：本镜机位相对前镜不越 180° 轴线
- [ ] 禁现代元素/乱码文字/塑料质感（复用负面词表）
- [ ] 成片层：2-3% 胶片颗粒 + 环境底噪 + 声音三层混音（1.0/0.4/0.18）

## 五、去AI感速查（被质疑"AI感重"时逐条排查）

1. 动作过多/morph → 拆成"一镜一动"，动作计数化
2. 运镜丝滑无重量 → 换"轻微手持漂移/固定"并加呼吸感
3. 画面太干净 → 加胶片颗粒+环境底噪+轻微压缩
4. 相邻镜不一致 → 检查全局设定词是否被改动，回用锚点原词
5. 转场生硬 → 改用 J-cut 声音先入或 Match cut 视觉匹配
6. 声音断档 → 检查三层混音与 J/L-cut 声画错位
