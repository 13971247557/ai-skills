# skill-history-check 历史技能核查

## 硬规则（不可越过）

1. **操作前核查**：每次要使用某个技能/经验/蒸馏文件前，先核对它的结论是否与下列之一冲突：
   - 用户最新上传的参考图（参考图是权威，技能结论与参考图不符 = 技能错误）
   - 最新一轮网上调研的一手信源（官方规范、司法鉴定标准、实物照片）
   - 用户最近的验收结论（被用户否决≥2次的参数 = 技能错误）
2. **出错即删重调研**：技能结论被证错 → 立即执行：
   a. 删除错误技能文件（或改名为 `_废弃_<日期>` 保留审计，禁止继续引用）
   b. 重新调研（一手信源/参考图为准）
   c. 蒸馏正确版本并写清"旧错新对"教训
3. **防复用**：所有蒸馏文件必须记录"错误源参数"与"正确参数"对照，防止同类错误再次被照抄。
4. **验收锚定**：用户否决≠再试一版，先检查是不是技能参数错；是 → 走第2条，不是 → 才调参重做。
