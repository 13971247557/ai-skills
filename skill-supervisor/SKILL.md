# skill-supervisor（技能运用监督门禁）

> 用途：防止"skill写了、生成时忘了用"。每次生成前，本门禁必须跑一遍并显式回答；任何一条没过，停下来补，不许硬生成。

## 最高规则
- **每次** image_gen / image_edit / 视频生成 / 长文案生成 前，必须先读本门禁。
- 不允许"我记得规则"就跳过。凭记忆=没读。
- 生成前先在对话里打印检查结果（哪怕一句"门禁通过"），用户能看到。

## 生成前必过清单（逐条打勾）

### A. 锚点统一检查
- [ ] 这个项目的角色锁定脸已经生成并确认？（通用做法见 `consistency-lock`：建干净参考图集+元素绑定）
- [ ] 场景/结构锚点图已经生成并确认？
- [ ] 主角/配角身份块（发型/衣服颜色/年龄/标志道具）逐字一致，没换同义词？（换同义词=换人）
- 如果任一项否 → 停，先画锚点，不许出视频。

### B. 静帧先行检查
- [ ] 这个镜头的首帧静图已经生成并经用户确认？
- [ ] 没有跳过静帧直接跑视频？
- 如果否 → 停，先出静帧。

### C. 单镜跨度检查（血泪教训）
- [ ] 这一镜只演**一个主动作**？
- [ ] 没有把"外景→穿门→入体"这种大跨度塞进一条？
- [ ] 超过5s的长镜头，动作是否能在5s内自然完成？跨度大就拆条。
- 如果一镜跨了多个场景/动作 → 拆成多条，每条5s。

### D. 七槽prompt检查（调 consistency-lock）
- [ ] 机位槽（站哪+人眼高+焦段）
- [ ] 材质槽（每种材料带表面处理）
- [ ] 家具槽（位置+尺寸）
- [ ] 光线槽（主光方向+补光+时刻）
- [ ] 纵深槽（前景→中景→背景）
- [ ] 风格槽（一种媒介，别混）
- [ ] 负面槽（无文字/无水印/无畸形/无现代穿帮）
- 缺任何一槽 → 回去补，不许生成。

### D2. 提示词结尾转场设计（跨镜衔接预埋）
- [ ] 每镜提示词结尾写了针对当时画面效果的转场（运动/打击/遮挡/相似体）？（详见 `ai-short-drama-pipeline/references/scene-chaining.md`）
- [ ] 跨生成段边界准备用"上段末帧=下段首帧锚（Last-Frame Seed）"？
- 缺 → 回分镜层补转场设计，生成前就埋好衔接，不靠后期救。

### D3. 提示词质量评分卡（7 要素，借鉴提示词优化模型）
- [ ] 任务（这镜干什么，一个主动作）
- [ ] 主体角色（身份块逐字，参考图绑定）
- [ ] 约束（负面词：无文字/无水印/无畸形/无现代穿帮）
- [ ] 格式（时长+结构：景别→主体→环境→光线镜头句尾）
- [ ] 推理（动作链 6 节拍，长镜拆拍）
- [ ] 示例（参考镜头/锚点图引用）
- [ ] 风格（风格块逐字复用，不换同义词）
- 缺任一要素 → 回补，不许生成（方法详见 `ai-short-drama-pipeline/references/prompt-optimizer-models.md`）。

### E. 参考图绑定检查
- [ ] 生成时绑定了对应参考图（角色脸+场景图）？
- [ ] 不是纯文字让AI凭空造？
- 如果否 → 绑参考图，纯文字锁不住跨镜一致性。

### F. 积分/成本检查
- [ ] 这次生成花多少积分/钱，用户知道？
- [ ] 静帧阶段别烧贵的视频积分，先用便宜模式试。

## 生成后必查（抽帧验收）
- [ ] 抽25%/50%/75%三帧对照锚点：脸对不对？衣服颜色对不对？场景结构对不对？
- [ ] 有没有穿帮（现代物品/多手/乱码文字）？
- [ ] 跑了就带参考图重抽，不带病进下一步。

## 反模式（再犯就是没走门禁）
- ❌ 图没确认就直接跑视频
- ❌ 一条塞多个动作/多个场景
- ❌ 提示词凭记忆写，没读七槽
- ❌ 不绑参考图纯文字生成
- ❌ 失败后换个提示词再试，不回头查锚点
