# 免费渠道引擎（no-watermark-channels）

## 定位

本技能是**个人 AI 短视频自动化出片的生命线**：零现金预算，一切生成依赖免费渠道。生成素材时**先选渠道再出片**——渠道决定水印、免费额度、清晰度与排队速度。本引擎四个模块：

| 模块 | 职责 |
|---|---|
| **① 路由** | 按镜头需求（横屏/竖屏/长镜/对口型/图生视频…）推荐主渠道 |
| **② 监控** | 生成前查额度、盯活动窗口、记消耗日志、断崖预警 |
| **③ 发现** | 已知渠道全堵死时，按8条线索自动寻源新免费渠道，小样验证后回写档案 |
| **④ fallback** | 主→备→应急三级韧性链，任一渠道限流/断崖/停服自动切换 |

渠道实时档案（额度/水印/清晰度/自查入口/来源URL）见 `references/channels.md`。

## 六、主流程

1. **判需求**：镜头数量、单镜时长、清晰度要求、横竖屏、是否有Google访问、是否要求商用无水印。
2. **查一致性能力**：叙事片/有人物跨镜的镜头 → 只选 channels.md 〇.1 速查里 ★★★/★★☆ 渠道（支持参考图/首帧）；纯文生渠道只排给空镜/氛围镜。同一故事跨渠道时**共用同一套锚点图**。
3. **路由**：按第一节推荐链（含一致性优先链）选定主渠道。
4. **生成前查额度**：按第三节自查表逐项确认剩余额度，不足先攒/等刷新，不硬生成。
5. **执行生成**：
   - **清影** → `ark-video-pipeline/references/qingying-automation.md`（本链实测链路：底部「100积分」提交、network抓 `sfile.chatglm.cn/api/cogvideo/<uuid>_0.mp4` 签名票及时下载）；
   - **Veo** → `references/flow-automation.md` 浏览器自动化（首次需用户登录Google）；
   - **即梦对口型** → CLI `/home/user/.local/bin/dreamina-canvas`（`node create video --mode m2v`），衔接 lip-sync 技能。
   - **参考图纪律**：图生视频镜头一律传锚点图作首帧/参考（人物锚点+场景锚点双图，参考权重 0.6–0.8 起步），提示词只写本镜动作/运镜/神态，不重复描述锚点已有内容。
6. **水印判定**：抽帧查四角 → 裁切 / API无水印 / 换渠道。
7. **一致性复核（用户硬要求，2026-10-09 起强制）**：出片抽帧过 shot-asset-manager 一致性校验——人物查人物锚点（五官/发型/服装/神态），场景查场景锚点（光线/陈设位置/色调/时空）；跨渠道/跨镜任一不合格 → 同锚点图重出，不合格不进成片。
8. **复核**：清晰度达标、无崩坏、无水印残留（shot-asset-manager 水印复核），记消耗日志。

## 硬规则

- **成片不带水印**：任何渠道产物进成片前必须过水印判定；有水印先试剪辑端裁切，损失构图则换渠道重生成。
- **场景一致性零差错（用户硬要求）**：无论走哪个渠道生成，跨镜/跨渠道主体+场景一致不得牺牲——叙事镜只走支持参考图/首帧的渠道（channels.md 〇.1 速查），同故事跨渠道共用同一锚点图，出片必须过 shot-asset-manager 一致性校验，不合格重出。
- **免费优先但质量第一**：质量>成本>速度；免费渠道质量不达标时允许临时付费无水印渠道，以"质量达标下的最低成本"为准。
- **生成前查额度**：额度不足先攒/等刷新，不硬生成。
- **全堵死启动自救**：已知渠道当天都不可用 → 按第四节8条线索探索新渠道，小样验证后回写 `references/channels.md`，**不直接告知用户"无免费渠道"**。
- **忠实提示词**：提示词原样采用，不增删改写。
