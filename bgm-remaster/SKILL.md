# 编曲重塑（bgm-remaster）

## 概述

输入：一段"歌词/人声不错、背景音乐难听"的歌曲音频 → 输出：保留原人声与歌词、换上新编曲伴奏、节奏情绪与歌词适配的成品。

**核心原则（用户硬要求，压过一切）**：
1. **质量第一**：分离出来的人声不干净就重新分离；生成的伴奏情绪不匹配就重新生成；不因省时、省算力接受低质结果。
2. **忠实用户提示词**：用户给出的新伴奏风格/情绪/速度描述**原样采用**（不增删、不自由发挥）；缺失参数（时长/格式）仅补默认值并在交付中标注。
3. **人声是主角**：歌词/演唱必须完整保留、清晰可辨；伴奏永远服务于人声，不淹没、不抢戏。

## 何时使用

- 用户提供一首歌（或一段演唱音频），说"歌词不错/唱得还行，但背景音乐太难听/编曲太差"
- 用户要求"重新编曲、重塑伴奏、换 BGM、重新配乐"且需保留原人声
- 已有人声轨但想要一套新的编曲/伴奏

## 工作流总览

| 步骤 | 做什么 | 产出物 | 路由 |
|---|---|---|---|
| 0 | 需求澄清 | 决策单（载体/风格/情绪/速度/输出格式） | 见「步骤0」 |
| 1 | 人声分离 | `vocal.wav` + `accompaniment_orig.wav`（备用） | byted-mediakit-audio（音轨分离）；需 6-stem/分鼓贝斯时用 UVR5 v5.6.0(Demucs v4)，见 workflow.md |
| 2 | 歌词与节奏分析 | 情绪标签 + 估算BPM + 段落结构 | `scripts/analyze_bpm.py` + 歌词映射 |
| 3 | 生成新伴奏 | `new_bgm.wav` | text_to_audio_plus / seed-audio；专业分轨走 Suno V6 Studio(12轨WAV+MIDI)，见 workflow.md |
| 4 | 适配与合成 | `remaster.mp3/wav` | ffmpeg 混音（参数见 workflow.md） |
| 5 | 质检与交付 | 质检报告 + 成品 | 见 `references/quality.md` |

## 步骤 0｜需求澄清

先问清（用户没说全的主动补齐）：
1. **歌曲载体**：本地音频文件路径 / 云端链接（决定怎么取音频）
2. **新伴奏方向**：风格（流行/民谣/摇滚/电子/古风/爵士/钢琴纯音等）、情绪（悲伤/治愈/热血/浪漫/悬疑等）、速度（慢/中/快或具体BPM）
3. **保留范围**：人声是否全保留（默认全保留）；原伴奏是否完全丢弃（默认丢弃，除非用户说"参考原伴奏的感觉"）
4. **输出格式**：mp3/wav，默认 mp3 320k

用户若已给出风格/情绪描述，**原样锁定**，不替用户改。

## 步骤 1｜人声分离

- 先 Read `byted-mediakit-audio/SKILL.md`，按其"人声与背景声分离"流程执行（本机已验证该技能族可用）。
- 产出：干人声轨 `vocal.wav`（无伴奏）、原伴奏轨 `accompaniment_orig.wav`（备用，万一用户改主意要参考）。
- **质控**：分离后必须试听/看波形核对——人声完整无吞字、无明显金属感/空洞感；不合格重新分离或换参数，不将就。

## 步骤 2｜歌词与节奏分析

1. **歌词情绪**：用户提供歌词则直接读；未提供则听人声轨（或让用户贴歌词）。用「歌词→情绪→编曲」映射表选方向（见 `references/workflow.md`）。
2. **估算 BPM**：`python3 scripts/analyze_bpm.py vocal.wav`（纯标准库，输出参考BPM区间）。人声节奏是伴奏速度的锚点。
3. **段落结构**：标出主歌/副歌/桥段位置（用户可告知，或按歌词情绪起伏推断），副歌处伴奏应有明显情绪抬升。

## 步骤 3｜生成新伴奏

- 工具：`text_to_audio_plus`（文生音频 WAV，支持音乐/伴奏）或按 `seed-audio` 路由。
- Prompt 模板（合并用户风格描述 + 分析结果，**用户描述原样嵌入**）：
  `纯伴奏、无演唱，{用户风格描述}，情绪{情绪}，节奏约{BPM}BPM，时长约{T}秒，包含前奏/主歌/副歌结构，副歌处情绪抬升，器乐编配清晰，无歌词无人声，结尾自然淡出`
- 一次生成后先试听核对情绪与节奏；不匹配就按用户反馈重新生成（质量第一，不为省次数将就）。

## 步骤 4｜适配与合成

用 ffmpeg（本机 4.4）把 `vocal.wav` + `new_bgm.wav` 混音成片，参数与命令见 `references/workflow.md`「合成参数」：
- 时长对齐：以人声轨长度为准，伴奏不足用 aloop/裁剪补足
- 音量平衡：人声 0dB 基准，伴奏压至约 -8dB（脚本用 volume≈0.4），副歌可微抬
- 淡入 0.5s / 淡出 1.5s，输出 H.264/AAC 或 mp3/wav（按用户要求）

## 步骤 5｜质检与交付

逐项过 `references/quality.md` 质检清单；不合格回到对应步骤重做，修好再交付。交付时说明：分离质量、伴奏来源、适配依据（BPM/情绪）、验证方式与剩余风险。

## 质量第一的执行纪律

- **人声分离不干净 → 重新分离**；**伴奏情绪不匹配 → 重新生成**；**合成后人声被淹 → 重调平衡**。
- 用户给的风格描述原样用；补充参数需在交付中标注"补充默认值"。
- 不因"免费/省积分"接受低于质量线的产物（沿用视频链路的同一原则）。
