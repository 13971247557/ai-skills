# 发布适配包（publish-pack）

## 定位

**成片做完，发布包要能直接用。** 本技能把"发什么标题、挂什么标签、勾什么声明、几点发、封面什么规格"一次性生成，用户选标题确认后即可发布。

## 流程

| 步骤 | 做什么 | 产出 |
|---|---|---|
| 1 | **定平台与题材**：用户指定或按内容推荐（竖屏→抖音/小红书/视频号，横屏深度→B站） | 平台清单 |
| 2 | **生成发布包**：`scripts/pack_gen.py` 输出各平台标题变体/标签/AI声明/时间/封面建议 | 发布包（md） |
| 3 | **用户选标题**：从变体里选 1 个（或让用户给自定义标题） | 定稿标题 |
| 4 | **补封面**：按规格生成封面（走 doubao-creative-design，大字高对比） | 封面图 |
| 5 | **发布检查**：AI 声明已勾选、标签挂好、评论区预埋互动 | 可发布状态 |

## 命令速查

```bash
# 生成发布包（控制台 + 文件）
python3 scripts/pack_gen.py --title "雨夜的街头，霓虹在流泪" \
  --platforms 抖音,小红书,视频号 --genre 情感 --hook 反转 --out publish_pack.md

# 只看某个平台的候选
python3 scripts/pack_gen.py --title "..." --platforms B站 --genre 悬疑
```

## 硬规则

- **AI 声明必挂**：所有平台勾选 AI 生成标识（《人工智能生成合成内容标识办法》2025-09-01 施行），不打标即限流/处罚；
- **标题用户确认**：生成的变体是候选，发布前必须用户选 1 个或给自定义标题，不直接拿占位发布；
- **平台适配**：标题/封面/发布时间按平台策略（见 platforms.md），不跨平台复用同一套；
- **封面不虚假**：不宣称实拍真人，AI 辅助如实标注。
