# 口型同步（lip-sync）

## 定位

**AI 生成视频的口型问题要在生成前规避，不在生成后硬修。** 本技能提供分层策略 + 分镜风险标记工具。

## 核心认知

- AI 图生/文生视频的说话镜头，**口型与配音基本对不上**（模型不懂音素）；
- 精确对口型工具链（2026-10 调研）：即梦 m2v（云端免装，限单人写实正脸）/ LatentSync v1.5（约 8GB 显存本地免费，v1.6 需 18GB）/ Wav2Lip（原型批量，嘴糊）；**本机无 GPU，优先云端/在线版**；
- 因此优先级：**规避（层1） > 对口型渠道（层2） > 剪辑补救（层3） > 专业工具（层4）**。

## 流程

| 步骤 | 做什么 | 产出 |
|---|---|---|
| 1 | **分镜风险标记**：分镜表过 `scripts/risk_marker.py`，标出高/中/低风险镜头 | 风险标记 |
| 2 | **高风险镜头规避**：按 `references/strategy.md` 层 1 手法改分镜（改景别/遮挡/拆短镜/旁白化） | 改后分镜表 |
| 3 | **生成**：仍有对白硬需求 → 选支持对口型的渠道/功能（清影/可灵对口型、剪映数字人；生成前报价确认） | 镜头素材 |
| 4 | **剪辑补救**：口型仍不对的镜头切短/遮挡/旁白化 + 配音对齐 ≤0.2s | 成片 |
| 5 | **交付检查**：口型无明显不同步、声画同步达标（随完整性检查）；**老年角色镜头额外抽帧目检口型** | 验收 |

> **老年角色对白专项（老奶奶/老爷爷）**：老年角色音色语速慢、字音拖长，口型错位比青年角色更显眼——单句 ≤8 字、正脸近景对白 ≤1.5s 到点切走（切手部/物件/背影/空镜）、必须长正脸对白才走即梦 m2v（`/home/user/.local/bin/dreamina-canvas node create video --mode m2v`，限单人写实正脸）、配音先定稿再对画面（≤0.2s）、语气词（哎/哟/哦/咩）单独成短句；描述音色用"温和慈祥/慢悠悠"，禁用"苍老/低沉/沙哑"。完整规则见 `references/strategy.md`「老年角色对白专项」。

## 命令速查

```bash
# 分镜表口型风险标记（高=正脸近景+对白，建议规避）
python3 scripts/risk_marker.py --shots 分镜表.csv
python3 scripts/risk_marker.py --shots 分镜表.csv --out marks.csv
```

## 硬规则

- **生成前先过风险标记**：高风险镜头（正脸近景+长对白）不进生成流程，先改分镜；
- **规避优先**：能改分镜就不依赖对口型工具；对口型渠道消耗大，用前报价；
- **不硬修口型**：已生成素材口型不对 → 切短/遮挡/旁白化，不贴 Wav2Lip 幻想（本机跑不了）；
- **声画同步底线**：配音首字对齐画面 ≤0.2s（随交付前完整性检查）。
