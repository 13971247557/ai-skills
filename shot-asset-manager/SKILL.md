# 镜头资产管理（shot-asset-manager）

## 最高原则：出片质量第一位，一致性零差错（用户硬要求）

**跨镜头主体一致是讲故事的前提，任何不一致都不能进成片。** 同一角色/场景/关键道具，跨镜头必须完全一致；不一致就重抽，不妥协、不解释、不带入成片。

## 核心流程（每次多镜头制作必走）——即梦式「素材图先行」工作流

> 用户最高诉求（2026-10-11）：**"先出各种人物的素材图和场景图，然后才去找 AI 生成视频，像即梦一样"**。
> 即：每个角色一套**多视图锚点资产包**（正面/侧面/背面/表情变体/服装变体），每个场景一套**多景别锚点资产包**（全景/中景/细节/光照变体）；素材图阶段就精修，不是生成视频后才补救。细则见 `references/anchor-workflow.md`。

| 阶段 | 做什么 | 产出 |
|---|---|---|
| 1 | **角色多视图锚点生成**：每角色按产出清单出主参考正面 + 侧面 + 背面 + 表情变体（+服装变体） | 角色锚点资产包 png（走 doubao-creative-design 生成，变体一律 image_edit 传母图） |
| 2 | **场景多景别锚点生成**：每场景按产出清单出全景 + 中景 + 细节（+光照变体） | 场景锚点资产包 png |
| 3 | **用户审核（硬关卡）**：每张锚点图逐张单独交付 → 逐张确认；缺图不进 i2v | 用户逐张确认的锚点图 |
| 4 | **资产锁定**：登记资产清单（主参考 + 各变体用途），明确每镜引用哪张；锁定唯一锚点、禁止换锚点重开 | 资产清单（含角色×场景×镜号引用矩阵） |
| 5 | **每镜图生视频**：按镜头需要选对应锚点图作首帧/参考（侧面镜用侧面锚点、夜戏用夜光照变体），同一身份锚点不换 | 镜头视频素材 |
| 6 | **一致性校验（合成前）**：逐镜抽帧，对照该镜引用的锚点图核验（不是只对主参考硬套） | 校验结论（全部通过才进剪辑） |
| 7 | **剪辑去水印（合成时）**：素材带角标且素材端无法去水印时，剪辑端处理 | 无水印成片 |

**任何一步不通过 → 回到对应阶段重做，不带到下一步。**

> 以下阶段 1–2 的资产包产出清单、阶段 3 的审核清单、阶段 4 的锁定规则、首帧精修命令链、九宫格分镜蓝图、锚点图→i2v 引用规则，统一见 `references/anchor-workflow.md`（可执行命令/模板/决策分支齐全）。原有单张设定图规范（主参考拍摄规范、延展图漂移防控）仍然有效，是本资产包的母图制作基础。

## 阶段 1｜设定图生成（必须走 doubao-creative-design）

- 生成前必须读取 `doubao-creative-design/SKILL.md`，走它的澄清门禁与模型改写流程（生图前：产物路由锁定 → 澄清门禁 → 模型改写读取）。
- 每个核心角色一张设定图；关键场景一张设定图。多角色/多场景分张生成。
- 设定图要求：主体正面/半侧面清晰、服装发型完整、无遮挡、无文字乱码；背景简单干净（方便图生视频延续）。
- **主参考图（Master Reference）拍摄规范（2026-10 精研落地）**：中近景、**头部占画面 25–35%**、居中正面、不极端仰俯侧；**中性干净背景**（素墙/无缝布，杂乱背景会漏色漏风格）；**单一主光轴**（如相机左 45° 柔光），避免混合色温、避免强逆光、对比别太戏剧化（否则被"烤"进身份）；锁定战役造型（发型/服装/关键配饰），**避开密条纹/细小格纹**（会在帧间抖动变形）。只靠 prompt + 固定 seed 锁不住脸——视觉参考才是身份保持的必需品（去掉视觉锚点机制，角色一致性分数从 7.99 崩到 0.55）。完整规范与多镜头 SOP 见 `references/consistency.md`「主参考图与身份块锚定（2026-10）」。
- **延展图硬规则（2026-10 打磨）**：①生成前必须 Read 母图真实像素，记录核心陈设与光线再写 prompt（禁止文字盲生成）；②延展一律 `image_edit` 传母图 URL + scene-focused prompt（已锁定外观不重复描述）；③参考强度 0.6–0.8；④每 2–5 张对照母图查漂移，漂移回母图重延展（完整 SOP 见 `references/consistency.md`「延展图生成与漂移防控」）。
- **生成一张立即交付一张**（doubao-creative-design 硬规则），不得攒批。

### 阶段 1 扩展：角色多视图 + 场景多景别锚点资产包（2026-10-11 升级）

> 旧做法每角色/每场景只出 1 张设定图；新做法（用户硬要求 + 拆解实证）每个角色一套多视图锚点包、每个场景一套多景别锚点包。完整产出清单表见 `references/anchor-workflow.md` 第 1、2 节。

- **角色必出**：主参考正面（母图）+ 侧面（3/4 侧/正侧）+ 背面 + 每个 distinct 情绪状态一张表情变体；有换装剧情才出服装变体。**最少 3 张**（正面+侧面+背面）。
- **场景必出**：全景锚点 + 中景锚点；有特写戏加细节锚点；时间跨晨/昏/夜才出光照变体。**最少 2 张**（全景+中景）。
- **变体图一律 `image_edit` 传母图 URL 生成**，prompt 只写「保留[身份块逐字]，转为[角度/表情/景别/光线]」——禁止 `image_gen` 凭文字重画变体（文字锁不住身份，重画必漂移）。
- **素材图阶段就精修**：首帧精修（局部重绘）是爆款质量真正来源（影视飓风大鱼实证："磨提示词是优化不是彻底解决，P 图更高效"）。基础图构图 OK 但局部不对 → `image_edit` 只改出错区域，禁止整段重跑。命令链见 `references/anchor-workflow.md` 第 5 节。
- **缺图不进入 i2v**：产出清单上列的图没出齐、没逐张审核通过，禁止开始任何镜头视频生成。

## 阶段 2｜用户审核（硬关卡，不可跳过）

- 每张设定图**单独**交付用户查看（present_files / RichMediaCard）。
- 用户确认前：不生成任何镜头视频、不继续后续任何步骤。
- 用户提修改意见：按意见重生成该图并再次交付，直到确认。
- 审核内容提示用户：主体形象/服装/气质是否符合想象、场景色调是否符合。

### 阶段 2 扩展：多视图/多景别审核清单（2026-10-11 升级）

> 素材图先行后，审核粒度升级为逐张核对「跨视图是不是同一个人/同一个空间」。完整核对项见 `references/anchor-workflow.md` 第 3 节，要点：

- **人物变体图核对**：侧面/背面/表情变体与主参考图是不是**同一个人**（脸型轮廓/发型/服装一致）；表情变体只变神情、骨相五官不变；
- **场景变体图核对**：中景/细节/光照变体与全景图是不是**同一个空间**（陈设样式数量位置不变，只有景别/光线变）；
- **缺图拦截**：产出清单上还有图没出齐、没逐张确认，一律不进 i2v。

## 阶段 3｜资产锁定

- 为每张确认图登记：`角色名 / 文件名 / 本地路径+URL / 主体描述（脸、发型、服装、气质）`。
- 登记后该图即为**唯一参考**：所有镜头图生视频只引用它，不换图、不重开。
- 资产清单写进镜头表（每镜标注 `设定图A`），供合成后校验。

### 阶段 3 扩展：锚点包锁定规则（2026-10-11 升级）

> 旧规则「一个角色一张唯一参考图」升级为「一个角色一套锚点包，主参考为默认首帧、变体图按需引用」。完整规则见 `references/anchor-workflow.md` 第 4 节，要点：

- **主参考 = 默认首帧**：无特殊需求的镜头人物一律用主参考正面图；
- **变体按需引用**：侧面/背面构图才用对应角度锚点；某情绪戏才用对应表情变体；换装段落才用服装变体；中景/特写才用对应景别场景锚点；对应时段才用对应光照变体；
- **每镜引用声明写进提示词**：「图1=人物主参考锁脸/服装，图2=场景全景锁陈设，图3=表情变体锁本镜情绪」——逐张写明用途，**禁止「全部参考」**（即梦手册纪律）；
- **禁止换锚点重开**：生成不一致时用同一张已锁定锚点图重抽该镜，禁止重新生成「更像的」锚点图（换图=重新漂移）；
- **身份块逐字不变**：不管用哪张变体图，提示词里身份块句与母版逐字一致。

## 阶段 4｜每镜图生视频（按镜头选对应锚点图）

- 每个镜头：`对应锚点图（按镜头特征选）+ 镜头提示词 → 图生视频`（走 ark-video-pipeline / 清影 / 方舟 i2v）。
- 镜头提示词只描述**该镜头的动作/运镜/氛围**，主体描述复用锚点身份块，不重复改写形象。
- 同一身份锚点不换：同一角色的镜头用同一套角色锚点包，禁止中途换锚点重开。
- 提示词忠实执行：用户给的提示词原样采用（见 ark-video-pipeline 忠实提示词规则）。

### 阶段 4 扩展：锚点图→i2v 引用规则 + 九宫格分镜（2026-10-11 升级）

> 完整引用决策表（侧面镜用哪张/特写用哪张/夜戏用哪张）见 `references/anchor-workflow.md` 第 7 节；与提示词三层衔接：第一层素材图论文级长提示词、第三层每镜 i2v 短提示词，均见 `../prompt-engineering/references/video.md`。

- **分镜阶段先用九宫格定每镜画面**（B线资产 A3）：LLM 出 N 镜脚本后，N 条镜描述用分号隔开，一次性生成 3×3 九宫格「院线级连续截图」分镜蓝图 → 用户逐格审核 → 再逐格 i2v。命令串见 `references/anchor-workflow.md` 第 6 节。
- **每镜引用声明拼在 i2v 短提示词前**：「图1=人物主参考锁脸/服装，图2=场景全景锁陈设，图3=表情变体锁本镜情绪」，禁止「全部参考」。
- **首尾帧/一镜到底**：提示词以「图1为视频首帧：<复述图1内容>」「图2为视频尾帧：<复述图2>」开头；≥10s 时长中段崩坏高发区插第三张中锚点图；「转半圈」不转一圈。规则见 `references/anchor-workflow.md` 第 7.2 节。

## 阶段 5｜一致性校验（合成前必过）——人物/场景双锚点

逐镜抽帧（`scripts/frame_extract.py`），**人物查人物锚点、场景查场景锚点、时空查分镜表**（双锚点+锚点网络完整规则见 `references/consistency.md`）：

**人物专项**

- [ ] 五官/发型/服装/气质 vs 人物母图一致（无变脸/换装/年龄漂移）
- [ ] **身份块文字逐字比对（2026-10 强化）**：每镜提示词开头的身份块（年龄/发型/服装/配饰/五官标记）与"制作圣经"母版**逐字一致、一字不改**（"red cap" 和 "red baseball cap" 在模型眼里是两个输入）；校验时把该镜 prompt 身份块与母版并排比对，有任何改词/缩写/换同义词即判该镜不合格、退回重抽
- [ ] **神态与每镜情绪一致**（形一致·神变化：外形锁定、表情随情境变，不复制母图表情到全片，泪点镜不带笑意；反面案例如 M23b' 反复笑意→改背影规避）

**场景专项**

- [ ] 光线方向/色温 vs 场景母图一致
- [ ] 核心陈设（纱帘/茶具/桌椅/门/窗台）位置样式一致
- [ ] **物体位置一致+不出镜**（核心陈设相对位置与布局基准一致，完整入画不被裁切，大小比例稳定）
- [ ] 色调影调一致

**时空专项**

- [ ] 晨/昼/夜与分镜表一致、季节天气无突变
- [ ] **场景意象与故事线匹配**（现代/古风语汇一致、空镜承载叙事时空、切换有动机）

- 任一镜任一专项不合格 → 用同一母图重抽该镜，不合格不进成片

**场景合理性专项（交付前必过，清单见 `references/consistency.md`「场景合理性自检清单」）**

- [ ] 晨/昼/夜与分镜表一致、时间流动有序
- [ ] 人物位置/动作空间连续可追溯，剪影镜角色含义明确
- [ ] 物理逻辑符合生活常识（投递/送信时间、光源、陈设位置）
- [ ] 意象语汇统一、城市/家/窗外全片同一锚点
- [ ] 场景切换有故事动机；升华动作与故事线一致（不做坐着/站着混淆）

## 阶段 6｜剪辑端去水印（素材端无法去水印时）

用户硬要求：**成片不带水印**。素材生成无法去水印时，剪辑端处理（完整规则见 `references/watermark.md`）：

1. 先尝试素材端去水印（清影网页开启去水印参数/付费档渠道）。
2. 素材端不行 → 剪辑端兜底（按水印位置优先级）：
   - **裁切**：角标位于固定角落 → ffmpeg crop 裁掉含角标的安全区（损失少量边缘画面）；竖屏/横屏都适用，裁后需重审构图主体是否完整。
   - **擦除**：画面内容允许时用视频编辑工具对角标区域做模糊/覆盖（慎用，可能留痕）。
3. 去水印后必须抽帧复核：四角无平台角标、主体未受损。
4. 合成脚本（video-edit-pipeline/build_video.py）支持 `--crop-watermark` 参数自动裁角标区（见下）。

## 命令速查

```bash
# 抽帧审核/一致性/水印检查（按秒抽帧）
python3 scripts/frame_extract.py --video shot-01.mp4 --out ./frames --times 1,3,5

# 抽满全片帧（逐帧检查一致性/水印）
python3 scripts/frame_extract.py --video shot-01.mp4 --out ./frames --all

# 合成时裁掉右下角标（W*0.85 × H*0.85 裁切后回放，示例参数）
python3 ../video-edit-pipeline/scripts/build_video.py --clips ./clips --out final.mp4 --ratio 9:16 --crop-watermark "0.86:0.0:0.14:0.14" --voice voice.mp3 --subtitle sub.srt
```

`--crop-watermark` 格式：`右保留下:x保留右:底去除:右去除`（相对值 0~1），按水印实际位置调整；不传则不去。

## 与其它技能的分工

- `ai-short-video`：文案/分镜/爆款方法论 → 镜头表（标注每镜用哪张设定图）
- `ark-video-pipeline`：实际生成设定图与镜头视频（忠实提示词）
- `shot-asset-manager`（本技能）：设定图审核、资产锁定、一致性校验、剪辑端去水印
- `video-edit-pipeline`：合成成片（支持 `--crop-watermark`）
- `bgm-remaster`：BGM 编曲重塑
