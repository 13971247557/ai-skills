# 分镜表批量生成（storyboard-to-assets）

## 一、工作流

1. **前置**：分镜表已定稿（`ai-short-drama-pipeline/references/storyboard-contract.md` 格式：镜头ID/时间/画面动作/镜头语言/画面设计/声音与文字…）；
2. **跑脚本**（自动组装初稿）：

```bash
python3 scripts/storyboard2prompt.py 分镜表.md --format both
# 输出同目录 storyboard-prompts.md：每镜=分镜图提示词 + 视频提示词骨架
```

3. **分镜图批量出图**：把每镜"分镜图提示词"交给 doubao-creative-design 批量生成分镜图（角色/场景锚点作为参考图传入，保持一致性）；
4. **视频提示词细化**：骨架按平台分支展开——
   - 跳跃视界 H3：八段式（全局设定/参考图用途/第0秒锁定/画面时间线/配音/环境音/转场/一致性禁区）；
   - 豆包 Seedance：五段式（输入资产定位/主体绑定/逐时间段/转场尾态/一致性禁区）；
5. **门禁后进生成**：每镜细化稿过 qc-checklist 再提交，禁未细化直接生成。

## 二、脚本说明（scripts/storyboard2prompt.py）

- 纯标准库（re/parse），无需装依赖；
- 解析 Markdown 表格（表头须含 镜头ID|时间|画面动作|镜头语言，自动跳过空行/分隔行）；
- 输出两种初稿：分镜图提示词（冻结一帧，含主体/动作瞬间/镜头语言/画面设计）；视频提示词骨架（动作链+镜头+声音，标"按平台分支展开"）；
- 支持 `--format 分镜图|视频骨架|both`。

## 三、门禁

- 输入分镜表已过 storyboard 客观校验（时间连续/台词密度/总时长整数）；
- 输出清单覆盖全部镜头（无遗漏）；
- 分镜图生成时角色/场景锚点作为参考图（不用裸提示词硬画）；
- 视频提示词必须平台分支细化后才提交生成（骨架不是终稿）。

## 四、与总控衔接

挂在 `video-command-center` 第 3-4 环之间：分镜表定稿 → 本技能批量出分镜图+提示词初稿 → 资产锚点已就位 → 进生成环。
