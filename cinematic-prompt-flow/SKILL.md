# cinematic-prompt-flow（电影感提示词导演流）

> 来源（2026-10-19 蒸馏）：抖音博主"贿赂上帝-"/OAK 分享的电影化图像探索流程 + "4种AI电影级场景提示词"模板（东方市井/超现实空间/生命树祭典/深海异境）。

## 一、电影提示导演工作流（输入→9个电影画面）

**核心思路**：让 AI 扮演「电影提示导演 + 视觉构图设计师」，不管输入是简单想法、场景描述还是上传一张图，都输出 N 个独特的电影画面提示，重点放在**构图、镜头、布景、视觉叙事**。

系统提示词（可直贴，配合 3.1/5.5 模型）：
```
你是一名电影提示导演和视觉构图设计师。请基于用户的输入（简单想法/场景描述/图片），给出9个独特的电影画面提示，每个提示聚焦：构图、镜头（焦段/角度/运动）、布景（环境/道具）、视觉叙事（人物动作/光影/氛围）。风格化、电影感、有概念发散。
```

用法：
1. 一个节点贴上述系统提示词，另一个节点写"脑海中的场景"（一句话即可）
2. 两节点合并输出 → 9 个电影画面提示
3. 提示词接入生图节点（Lib lmage 等）→ 出九宫格电影感画面
4. 九宫格切分 → 单独放大喜欢的分镜；角色设定图/场景设定图/脸部三视图可一键出

**高阶玩法（风格后缀直出）**：只用提示词的英文部分 + 风格后缀 + `review` 后缀，可调用最新未发布的 M 8.2 模型直出；虽与上传图场景不完全一致，但风格调性与概念发散极强。

## 二、场景提示词六要素模板（电影级场景通用骨架）

任何"电影级场景"提示词按六要素组织，缺一不可：

| 要素 | 内容 | 示例（东方市井） |
|---|---|---|
| ①影调锚定 | 引用经典电影风格定影调 | 《末代皇帝》《卧虎藏龙》式东方经典电影影调 |
| ②色彩对比系统 | 明确主色+对比色 | 温润朱红、琥珀金灯光 与 冷青雨夜 强烈对比 |
| ③层次置景 | 分上/中/下三层堆密度 | 上层=微湿布幡/招牌/竹鸟笼/雨水帘；中层=香料摊/蒸汽铜壶/青花瓷/蓝染布；地面=倒影斑驳青石板/泥泞车辙 |
| ④角色协同 | 多组角色各司其职同框运转 | 商人黄铜秤称香料/学徒抱瓷器穿梭/贵妇扯布验质/铜匠錾刻/搬运工前景横压/行客骑手斜穿/孩童追逐 |
| ⑤镜头语言 | 明确运动+揭示结构 | 平滑前推横移；前景动态遮挡移开瞬间揭示微观交易细节 |
| ⑥高潮定格 | 收束为一张海报级画面 | 三层古戏楼大红帷幕拉开，篝火击鼓彩绣舞者爆发，雨丝蒸汽火光人群车马交织定格 |

## 三、四类现成场景模板（浓缩版）

1. **东方市井**：末代皇帝+卧虎藏龙影调；朱红/琥珀金/冷青对比；唐宋市井+西域风情三层置景；八组角色；15秒一镜到底；前景遮挡揭示；古戏楼帷幕高潮定格。
2. **超现实空间**：空间透视错乱/埃舍尔式；单一世界规则打破（楼梯无尽/房间嵌套/重力翻转）；高密度细节；人物小比例强化尺度震撼。
3. **生命树祭典**：巨树/根系贯穿多层空间；螺旋贝壳图书馆/发光海藻森林；孩童追逐荧光生物；巨型水母提灯点亮瞬间+日光纵深光束。
4. **深海异境**：阿凡达水之道+海王+少年派影调；深海靛蓝/青绿/生物荧光蓝/紫罗兰主色+珊瑚点缀；垂直几百米深海城市（活体珊瑚/贝壳/鲸骨/沉船/发光海葵）；四层垂直文明体系（底层集市/中层枢纽/巡航巨鲸/商队海龟）；15秒一镜到底。

## 四、门禁

1. 每个场景先定**影调锚定+色彩对比**再写其余要素（影调是电影感的根）
2. 层次置景必须≥3层（高密度=电影感，空场景=CG感）
3. 角色协同写**具体动作**（谁做什么），不写"人群热闹"空泛词
4. 镜头语言写"运动+揭示"（前推/横移/遮挡揭示），不写静态描述
5. 高潮定格=整段提示词收束点，必须有
6. 本项目（《她的名字》）真实感需求与本法兼容：把"影调锚定"换成"80-90年代机关档案室冷白日光灯+胶片颗粒"，"层次置景"换成"柜列/卷宗/文件堆/纸箱生活痕迹"，"角色协同"换成单人手部动作细节——真实感=低密度高细节，电影感=高密度高调度，按题材取舍

## 五、顶级提示词打磨（年代真实感导演维度·2026-10-19 实战版）

年代剧/真实感资产生成的最顶级提示词 = 三重事实源（剧本分镜 + 现实调研 + 六要素）叠加导演维度。任何一重缺失即为不合格。

### 5.1 三重事实源先行（写提示词前必过）

1. **剧本分镜事实**：该资产对应哪个场次/镜号/机位/职责/情绪（谁在何时何地以何状态出现）——无分镜依据不生成。
2. **现实调研事实**：上网查真实世界对应物的存在形态/形制/材质/使用方式，调研结论（形制特征+年代细节）必须写进提示词正文，禁止凭空脑补。
3. **六要素组织**：影调锚定→色彩对比→层次置景→角色/主体协同→镜头语言→高潮定格，按题材取舍密度。

### 5.2 资产类提示词模板（无背景角色/道具/动作，六要素改造版）

统一前缀锁定：`浅灰纯色无背景、单一主体居中、主体完整入画、无投影装饰`（防贴片穿帮）。

- **影调锚定**：写实年代摄影；主光方向（左/右/顶）+ 色温（冷白荧光/暖黄钨丝/白炽）+ 媒介（胶片颗粒/暗房质感）
- **色彩对比**：主体固有色精确（禁"深蓝"漂成"紫"：写"灰蓝工装，色相偏青不偏紫"）
- **层次置景（主体级）**：主体自身的结构细节分层描述（例：双开门柜=两门+中柱+锁芯+拉手+锈迹分点列出），≥3 层细节
- **角色/主体协同（主体级）**：动作瞬间定格（手指怎么放/钥匙角度/卷宗姿态），写具体不做空泛
- **镜头语言**：机位（平视/微俯/特写）+ 焦段感 + 运动（极缓慢推近/固定）
- **高潮定格**：最终画面停在哪个状态（锁芯对焦清晰/卷宗边角微卷）

### 5.3 光影色温锁定法（防光色漂移——本项目最高频错误）

单靠"禁止暖光"压不住模型先验，必须正向锁定：

1. 首段写死色温事实：`冷白荧光灯管（色温约5000K偏青）、无任何暖色光源`
2. 逐段/逐格重复锚点：每个动作段都重申`冷白荧光灯照明、无暖光`
3. 反暖指令具体化：`窗户透入灰白晨光而非金色阳光；任何金黄/橙/夕阳色调均为错误`
4. 参考图校色：图生图/图生视频前可对参考图做冷白校色预处理（PIL 微降色温），锁死起点

### 5.4 防穿帮结构锁定句（可数物体/结构不漂移）

- 计数锁定：`窗户=3扇、柜门=2扇、锁芯=1枚`（可数项全部写死数量）
- 结构锁定：`双开门+两门中间竖直中柱+中柱正中锁芯+每扇门中部偏上同款横向长条拉手；柜内不画任何五金`
- 状态锁定：`柜门开合状态=右开左关`（动作段不消失/不变结构）
- 空间锁定：`机位固定微俯、构图与参考图一致，背景元素（桌椅/柜列/纸箱）不得增减移动`

### 5.5 真实质感词典（去AI塑料感，直接选用）

| 对象 | 质感词 |
|---|---|
| 金属 | 锈迹斑驳/边缘磨损露底漆/划痕/焊点/氧化暗斑 |
| 纸张 | 泛黄/边角卷起/纤维可见/折痕/水渍渍痕/脆裂边缘 |
| 木质 | 漆面开裂/虫孔/包浆/接缝发黑 |
| 织物 | 磨损起球/褪色/线头/领口变形 |
| 搪瓷 | 磕碰掉瓷/裂纹/杯底锈圈 |
| 皮肤 | 纹理真实/毛孔可见/薄茧/指节粗大/血管隐约 |
| 环境 | 浮尘在光束中可见/地面轻微积尘/角落蛛网 |

### 5.6 禁止项写法（必挂段）

`禁止：任何文字/字幕/水印/乱码/假Logo/品牌名、屏幕与手机留白、现代元素（拉链/塑料瓶/LED/电子闸/不锈钢）、主体结构变形、额外物体、水印平台UI`

### 5.7 交付前验收（防缩略图误判）

- 生成后必须用 PIL 分区裁图（顶部/中部/下方/左右侧）放大逐区核验
- 对照剧本分镜逐项核对（在/不在/方位/状态）
- 色温与主体色用放大裁图确认，不凭缩略图观察下结论
