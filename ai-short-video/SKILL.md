# AI 短视频全流程成片

## Overview

把「想做一条爆款 AI 视频」变成「一条能发出去的成片」：从选题、文案、分镜、画面生成、配音字幕到剪辑发布，7 个阶段串成一条流水线。技能本身不调用生成工具，而是**输出每一阶段可直接执行的成品文件**（剧本、镜头表、提示词包、字幕、发布包），你拿着文件去即梦/可灵/剪映等工具执行即可。

**核心原则**：AI 生成的是素材原料，不是成片。每一阶段都要质控，废片在生成端拦截，不拖到剪辑阶段抢救。

## 何时使用

- 「做一条 AI 短视频/AI 短剧」「帮我策划一个爆款视频」等完整制作需求
- 单环节求助：爆款选题、黄金3秒开头、分镜表、AI提示词、翻车修复
- 已有文案/素材，需要补全其余环节（从任一阶段切入，缺哪步补哪步）

## 工作流总览

| 阶段 | 做什么 | 产出物 |
|---|---|---|
| 0 | 需求澄清 + 选题决策 | 题材/平台/形式决策单 |
| 1 | 创意与钩子设计 | 一句话爆点 + 标题/开头钩子 |
| 2 | 文案脚本 | 剧本（单集计时结构，去AI化） |
| 3 | 分镜脚本 | 镜头表（画面/台词/AI提示词） |
| 4 | 画面生成 | 角色设定图 + 镜头素材库 |
| 5 | 配音与字幕 | 音轨 + 字幕文件 |
| 6 | 剪辑合成与质检 | 成片 |
| 7 | 平台适配发布 | 发布包（标题/封面/标签/AI声明） |

每阶段产出物落成独立标准文件（见「接口与产出物约定」），后续阶段只消费文件、不回溯重做。

**大片级标准跑法**：按 `../ai-video-director/references/pipeline-sop.md`（7 环节管线 SOP + 步骤序列 A-G）执行——先定情绪目标再选题、pre-vis 小样先行、音频先行定节奏、收尾升华。

## 阶段 0｜需求澄清与选题决策

先问清 5 件事（用户没说全的主动补齐）：

1. **题材**（悬疑/科幻玄幻/逆袭爽剧/甜宠/家庭情感/职场/口播/文旅/其他）
2. **平台**（抖音/快手/小红书/B站/视频号/多平台）
3. **形式**（竖屏短视频 15s-3min / 竖屏短剧 1-3min×N集 / 横屏中长视频）
4. **数量**（单条 / 系列 / 整部短剧，多少集）
5. **风格与预算**（漫剧/仿真人/写实；免费工具 or 付费算力）

**选题决策**：按「题材×爆款潜力矩阵」选（详见 `references/genres.md`），决策优先级：

1. **AI 适配度优先**：优先切入 AI 制作优势大的题材——悬疑惊悚、科幻玄幻、逆袭打脸爽剧、战神赘婿、穿越重生、萌宠（AI 成本低、无真人微表情翻车风险）；家庭情感/都市现实虽热度最高，但属真人实拍优势区，AI 做微表情易翻车，须谨慎。
2. **平台扶持方向**：悬疑创新、现实题材、都市群像、科幻玄幻是 2026 各平台重点扶持方向，选题靠拢可获得流量/现金激励。
3. **爆点前置判断**：选题必须能一句话讲清「观众为什么看」——反转、奇观、共鸣点三者至少占一个，否则换题。

## 阶段 1｜创意与钩子设计

> 制作手法对标见 `references/excellence-benchmarks.md`（同题材出圈案例反推手法：老奶奶温情赛道/卡点节奏/转场教科书案例）。
> **逐镜级对标**（一部标杆作品从头到尾怎么拍出来、本地怎么复刻）见 `references/film-library.md`——Air Head 高概念规避 / 丧尸清道夫三段式提示词 / Nightborne 伪纪录片体裁规避 / ANCESTRA 混合管线，含逐镜拉片表、可复用公式与本地复刻路径。想做"有作者性、能破圈"的片子，先在这里选一种可对标的生产模式。

输出：一句话爆点 + 标题钩子 + 开头钩子（详见 `references/methodology.md`）。

**一句话爆点公式**：`目标人群 + 最反常识的结果 + 不解释原因`

- 例：「我花三万块装修阳台，邻居说我脑子进水了」「转正当天被裁，下一秒我甩出另一家公司的 offer」

**黄金 3 秒开头**（7 种手法任选其一，前 3 秒必须命中）：

1. 矛盾/悬念前置：最颠覆的画面剪在最前面，不解释
2. 冲突反转三段式：`0-1s 冲突画面 → 1-2s 抛疑问 → 2-3s 反转提示`
3. 反差认知失调：「大家都说 A，但事实是 B」
4. 价值承诺直给：`结果数字 + 戳痛点 + 预告价值`（三句递进）
5. 痛点+悬念：「你的[痛点]？答案在最后三秒」
6. 提问勾引：说一半留一半
7. 人群喊话：「三十岁还没升职的打工人，停一下」

**叙事钩子五机制**（剧情/短剧类，DramaSo 爆款验证）：场中引爆 / 身份炸弹 / 公开羞辱 / 最后通牒 / 画面自相矛盾——前 3 秒必须引爆一个"必须看到答案的问题"，不靠前史不靠铺垫。详见 `references/methodology.md` §1.8。

**标题钩子**：好奇心缺口 + 自我相关 + 明确承诺；数字、反差、悬念词优先（8 种公式见 methodology.md）。

## 阶段 2｜文案脚本

输出：剧本文件。**这是全流程最重要的一步，爆款与否七成看文案。**

> **先打故事地基，再套爆款公式**：写文案前，若你的需求是"亲情/情感/催泪/成长"等需要情感内核的题材，先走 `references/storytelling.md` 的**故事创作 SOP（七步）**——S1 定主题 → S2 立人物（弧光/动机/欲望）→ S3 找母题道具 → S4 搭三幕/救猫咪节拍 → S5 排泪点四步情绪曲线 → S6 设计钩子与悬念 → S7 转剧本（含短剧五行格式+12 条校验）。**故事定稿前必过 `references/storytelling-gate.md` 定稿门禁**（叙事体量/三层自检/动机锁死/母题三现/细节一致/奇幻可见因/泪点细节/技术前置/交付附证据，十项检查全过才进分镜）。
> `storytelling.md` 是**故事根基层**（麦基鸿沟/人物弧光/冲突三层次/三幕25-50-25/救猫咪15拍/英雄之旅/情感共鸣/希区柯克炸弹/冰山留白/剧本化转化），回答"故事凭什么成立、凭什么打动人"；本阶段下面的"单集计时结构/反转爽点/付费卡点"来自 `references/methodology.md`，是**爆款公式层**。两者上下互补：先用 S1–S5 把人物-结构-情感打牢，再用下面的公式包装，避免"有爆款壳子没故事灵魂"。催泪亲情片注意是**反快节奏特例**（铺垫要慢要长），不要套爽剧的 3 秒一爆。

### 单集计时结构（竖屏短剧标准）

| 时间 | 结构 | 内容 |
|---|---|---|
| 0:00–0:30 | 强开场 | 直接呈现冲突/反常事件，黄金3秒钩子 |
| 0:30–1:20 | 对抗升级 | 1 次反转 + 情绪爆发点 |
| 1:20–2:00 | 悬念收尾 | 解决小冲突，抛出更大的谜团（钩向下一集） |

**节奏密度硬指标**：3 秒一情绪冲击、15 秒一剧情变化、45 秒一强期待；核心爆点放在 75%–90% 位置（约 80%），避开 50% 和 100%。

**反转与爽点**：单集 2–3 个反转；爽点用「打脸三拍」——言语进攻 → 反差揭示 → 物理/数字碾压；让观众比角色先知道真相（信息差），靠一句点破台词释放情绪。

**角色精简**：单集核心角色 ≤2 人，配角台词 ≤3 句；人物标签化（身份+反差，一衣一句 3 秒立人设）。

### 去AI化硬规则（文案必须过这关）

1. **口语化**：像人说话，短句、有停顿，禁止书面腔与排比堆砌
2. **个性化**：带具体细节和情绪（数字、地名、动作、语气词），不用通用模板句
3. **反机械化**：禁用 AI 高频词——「赋能」「抓手」「底层逻辑」「众所周知」「值得一提的是」「总而言之」「让我们」；抽象词一律换成具体行为

对照示例：

- ❌ AI味：「职场竞争日益激烈，年轻人面临着前所未有的挑战，我们应当积极应对。」
- ✅ 人味：「工位对面新来的那个同事，昨天还在朋友圈晒加班，今天早上 9 点 01 分，他的名字出现在裁员名单第一行。」

**心理描写必须转成可见动作**——AI 拍不出「她很悲伤」，只能拍「低头垂眸，眼眶泛红，双手紧握成拳，肩膀微颤」。

**多集短剧**：每集结尾抛新悬念；付费卡点设在本集情绪峰值处（付费点节奏：卡一 8–16 集、卡二 25–30 集、卡三 50 集左右，每 10 集一个付费点）。

## 阶段 3｜分镜脚本

输出：镜头表（每行一个镜头，标准字段见下），详见 `references/toolchain.md`。

**镜头表模板**（CSV/Markdown；2026-10 起每镜必含三要素）：

```csv
镜号,景别,时长秒,运镜,动作变化链,环境光影,画面内容,台词,AI提示词要点
01,特写,3,镜头缓慢推进,女主指尖捏通知→指节发白→拇指收紧,冷白屏幕光打脸,女主手捏着裁员通知,旁白:转正当天被裁,设定图A+首帧:通知特写
```

**每镜三要素（硬要求，与 prompt-engineering 第二层"分镜表"衔接）**：每镜必须写清这三栏，缺一补写——
1. **运镜**：固定 / 缓慢推进 / 跟随 / 横移 / 拉高拉远 / 手持晃动（用中文短词，不堆 cinematic）；
2. **动作变化链**：一个镜头内主体"从 A 状态变到 B 状态"的具体物理动作（"低头垂眸→眼眶泛红→肩膀微颤"），**情绪词必须翻译成身体动作**，禁止写"她很悲伤"；
3. **环境光影**：光线方向 + 色温 + 明暗（冷白屏幕光打脸 / 黄昏侧光 3200K / 逆光剪影）。

**分镜规则**：

1. 一个镜头只写一个动作/一个场景；心理描写一律转动作（同阶段 2）
2. 文生视频单镜时长 5–10 秒，超长镜头拆段；**想做长镜头（一镜到底/长镜叙事）时，手法与七步 SOP 见 `ark-video-pipeline/references/ai-video-generation-guide.md` 第 6 章**（选题→场景单一性→运镜单一连续→参考图固定→分段生成→无缝拼接→质检）
3. 每个镜头给出 AI 提示词要点（主体 + 动作 + 景别 + 光效 + 风格），供阶段 4 直接使用；**逐镜执行短提示词 20–60 字 = [景别运镜]+[动作变化链]+[环境光影]**，一镜只一个主动作
4. 台词按语速估时长：每 10 字 ≈ 2 秒；**剧情片默认主线无对白，对白改内心独白旁白**（AI 中文对白必出戏，见 ai-video-director 决策分支③）
5. 剧本不要整段丢给视频模型——按场拆段，每段只写一个场景

**九宫格分镜蓝图（前期构图预演，B线资产A3）**：镜头表定稿后，正式逐镜 i2v 前，可先一次性验证整片构图——
把 N 条镜提示词用分号隔开，一次文生一张 3×3 网格"院线级连续截图"分镜蓝图，检查整片景别/光线/顺序是否连贯，再逐格裁图喂 i2v：
```
ark image --prompt "<镜1提示>;<镜2提示>;…;<镜9提示>，一张3×3无边框网格电影连拍分镜图，按时间顺序排列，院线级连续截图，电影级布光HDR，画面中无文字" --size 1920x1920
```

## 阶段 4｜画面生成

输出：角色设定图 + 镜头素材库。工具与参数详见 `references/toolchain.md`。

**标准流水线（先建资产，后出片）**：

1. **角色设定图**（文生图）：先固定每个核心角色的形象（脸、服装、发型、气质），全片一致性全靠它——这是 AI 短剧最关键的资产
2. **场景设定图**（文生图）：关键场景固定一张底图
3. **镜头生成**（图生视频为主）：`角色设定图/场景图 + 分镜提示词 → 视频`；**一镜一参考图**，首帧用设定图保证人物一致
4. 先低清 Draft 快速验证构图与动作，通过后再高清生成；废片在生成端拦截

**一致性方案**：跨镜头/跨集保持角色 = 设定图 + 首帧参考 + 固定种子；多镜头同一动作要保留同一参考图。文字类画面（招牌、字幕）单独生成校验，避免乱码。**一致性深度教学（4+1 维度、平台一致性机制、SOP、抽帧质检命令、10 项生成注意事项）统一走 `ark-video-pipeline/references/consistency-guide.md`**，本阶段不重复列。

**翻车点速查**（完整版见 toolchain.md；**生成端 bug 全量排障手册见 `ark-video-pipeline/references/bug-troubleshooting.md`**——12 类 bug 四段式 + 平台特定坑 + 诊断决策树，翻车先查它）：

| 翻车点 | 规避 |
|---|---|
| 人物形象每镜都变 | 全程锚定角色设定图，禁止换图重开 |
| 口型对不上 | 优先口播短镜；配音定稿后再对齐画面 |
| 手部/多指崩坏 | 特写减少手部；生成后逐帧检查重抽 |
| 文字乱码 | 含字画面单独文生图，校验后合成 |
| 动作幅度小/镜头单一 | 提示词给明确动作动词+镜头运动（推近/环绕/晃动） |

## 阶段 5｜配音与字幕

- **配音**：优先平台自带 TTS（豆包/剪映配音、火山方舟 TTS API），先定音色再试听全文；短剧对白多时按角色分轨，口型镜头优先对口播。**场景→音色/语速/音量判定表、老奶奶/方言音色 ID 与 F0 性别质检，统一见 `video-edit-pipeline/references/audio.md`**（不要在本阶段重造音色表）；
- **字幕**：生成标准 SRT/ASS；短剧平台字幕字号偏大、留足底部安全区；AI 生成内容须在画面上加显式标识（见阶段 7）
- **口型同步**：先配音后生成/对齐口播画面；口型瑕疵用短镜头切换掩盖；嘴跟字错位/嘴糊/双嘴修复速查见 `references/excellence-benchmarks.md`「口型翻车速查」

## 阶段 6｜剪辑合成与质检

> 制作手法对标见 `references/excellence-benchmarks.md`（转场时长参数/60fps插帧/BGM压人声dB标准/卡点吸附0.35s/去水印兜底）。

- **剪辑**：剪映（CapCut）为主——素材按镜头号命名批量导入，套分镜表逐镜落位；BGM 音量低于人声 6–10dB；转场用硬切为主、特效转场每 10 秒至多 1 个
- **质检清单（发布前逐项过）**：
  - [ ] 黄金3秒钩子在前 3 秒真实成立
  - [ ] 人物形象跨镜头一致（逐镜对照设定图）
  - [ ] **场景合理性（逐镜必过，清单见 `shot-asset-manager/references/consistency.md`「场景合理性自检清单」：时空有序/行动可追溯/物理常识/意象统一/衔接有动机/升华动作与故事线一致）**
  - [ ] 口型与音轨同步、无掉帧/抽帧崩坏
  - [ ] 手部/文字无崩坏（含画面内中文字）
  - [ ] 节奏密度达标（3s/15s/45s 指标）
  - [ ] 结尾悬念/互动引导存在
  - [ ] 字幕完整无错别字、安全区未越界

> **交付前三项硬关卡**（字幕无重叠/成片可播/画面与字幕对齐，含 ffprobe 分辨率核对、抽帧目检字幕密集段）与完整发布前逐项检查、转场时长分档、响度 -14 LUFS 参数，统一走 `video-edit-pipeline/references/quality.md`——合成环节由 `video-edit-pipeline` 执行时直接对照其清单，不在本阶段重复列。

## 阶段 7｜平台适配发布

输出：发布包（标题 + 封面 + 标签 + AI 声明 + 差异化说明），详见 `references/platforms.md`。

**合规底座（强制，所有平台）**：国家《人工智能生成合成内容标识办法》2025-09-01 施行，AI 生成内容必须主动勾选平台「AI 声明/生成标识」，不打标即限流/处罚。

**平台差异化速查**：

| 平台 | 一句话策略 |
|---|---|
| 抖音 | 前3秒强钩子 + 竖屏强情绪打公域赛马；AI短剧走「真人主演+AI辅助」评级保底（A+级 50 万）最划算 |
| 快手 | 真实老铁感 + 私域互动养粉丝；绑定可灵 AI 厂牌拿星芒创投与分账 |
| 小红书 | 标题按搜索关键词写、真实体验叙事；AI 只做辅助放大器且必须标注，纯 AI 灌水最易被限 |
| B站 | AI 成片重剪为横屏深度内容，靠三连/弹幕进社区推荐；可冲「AI 动画剧场」专属频道 |
| 视频号 | 朋友圈/社群冷启动触发好友点赞涟漪；内容走平实路线，AI 标注合规第一 |

**通用发布动作**：标题带情绪/悬念或搜索词 → 封面大字高对比 → 挂 2–3 个话题标签 → 勾选 AI 声明 → 评论区预埋互动引导（抛问题/藏答案）。
