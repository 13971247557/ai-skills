# 年代剧声音资产生成（era-sound-asset）

## 定位

补 **sfx-layer 不覆盖的维度**：sfx-layer 是通用氛围垫底（雨/心跳/风/城市底噪），本技能管**剧本可点名的具体拟音与年代环境声**（谁在何时发出什么声音），每个声音是独立资产，可复用、可精修、可入库。

声音四层体系（全片）：
| 层 | 技能 | 示例 |
|---|---|---|
| 配音/人声 | elevenlabs-v4-voice / seed-audio | 旁白、对白 |
| BGM | bgm-selection | 配乐 |
| 环境氛围 bed | sfx-layer | 雨声、底噪 |
| **具体拟音/年代声（本技能）** | era-sound-asset | 钥匙碰撞、锁舌滑动、纸张摩擦、日光灯嗡鸣、午休铃、脚步、电视笑声、风扇、空调、夜风、心跳 |

## 流程（每项声音独立闭环）

| 步骤 | 做什么 | 产出 |
|---|---|---|
| 1 | **剧本声场提取**：从剧本/分镜提取该场景需要的声音（谁/何时/何动作/何环境），只生成剧本点名或剧情必需的声音 | 声音清单（编号+名称+声源+所在场/镜） |
| 2 | **选通道**（按真实感与成本优先级）：真实录音（免费库） > AI 生成 > 程序化合成（见下节；**可录音环境声禁用程序化合成**——用户已否决"噪音感"） | 通道决策 |
| 3 | **生成**：按规格生成单个 wav/mp3 资产 | 声音资产文件 |
| 4 | **验证**：时长/采样率/响度/听感四查（见验证节） | 验证记录 |
| 5 | **归档**：按类型放 `资产\声音\`，命名 `HN_声音_名称_Vxx_OK.wav`，更新资产清单 | 归档 |

## 通道细则（按真实感与成本优先，真实录音已升为首选）

### ① 真实录音免费素材库（首选，被否决的合成类声音全部用它）

环境声/拟音优先真实录音，质感远超 AI 合成与程序化合成：

- **SoundDino（sounddino.com）**：免登录/免署名/MP3 直下。分类页 HTML 提取 `data-track="/mp3/<id>/<slug>.mp3"` → 直链=`https://sounddino.com`+路径；**部分文件必须带 Referer（分类页 URL）下载否则返回 HTML**。已实测可下：房间荧光灯工作声/老式校铃/走廊脚步/硬地面走/电视连续剧式笑声/叶片切风/孤风近轻。
- **Freesound**：搜索页 `freesound.org/search/?q=<词>` 正则抓 `https://cdn.freesound.org/previews/<dir>/<id>_<uid>-lq.mp3` 预览直链（免登录）；心跳类有"Real Human Heartbeat-Contact Mic"真实录音。CC0 才可商用，CC-BY 需署名记录。
- 处理（无 ffmpeg）：`pip install soundfile`（自带 libsndfile 可解 mp3；**miniaudio 对本机 mp3 解码全失败弃用**）；重采样 np.interp、低通 FFT 截断、选段滑动 RMS。距离/隔墙只在实录基础上微调（脚步远=低通1200Hz+音量-14dB；电视隔墙=低通1000Hz+低音量；灯垫底 peak≈0.03），不过度加工。
- 记录来源与许可；下载后用 sf.read 核对采样率≥44.1kHz。

### ② AI 自然语言生成（次要，无法获得实录时）

用 seed-audio 技能（text_to_audio_plus）逐项生成。提示词必须写**声源+材质+动作+环境+时长**，如：

- 钥匙：`老旧黄铜钥匙串轻微碰撞声，金属质感清晰，短促清脆，室内安静环境，约1秒`
- 锁舌：`老式铁柜转舌锁锁舌滑动的金属摩擦声，低沉短促，约0.8秒`
- 纸张：`泛黄纸张翻动摩擦声，纸纤维质感，轻柔，约2秒`
- 日光灯：`老式日光灯管的低频嗡鸣声，持续稳定，带轻微电流底噪，约10秒`
- 脚步声：`深秋夜晚水泥走廊上的脚步声，由远及近，皮鞋底，约6秒`
- 电视笑声：`老旧电视播放情景喜剧的嘈杂笑声与掌声，隔着房间门传出的闷响，约5秒`
- 心跳：`清晰低频心跳声，节奏稳定约每分钟75拍，约8秒`

规格：单一声音单次生成；不拆分多次；时长整数秒便于平台/剪辑输入。

### ② 免费无版权素材库（真实录音优先）

真实录音质感 > AI 合成时用免费库（无版权可商用）：Freesound（freesound.org，需注意 CC0/署名）、网易云音效/站长素材等。下载后必须：
- 记录来源与许可（CC0 才可商用；CC-BY 需署名）；
- 用 ffprobe 核对采样率≥44.1kHz；
- 裁剪/循环/淡入淡出用 ffmpeg 处理（见下）。

### ③ 程序化合成（最后兜底；可录音环境声禁用，用户已否决"噪音感"）

参考 sfx-layer 本地合成思路，年代声常用配方：
| 声音 | 配方 |
|---|---|
| 心跳 | 低频正弦脉冲（约1.2Hz周期双搏）+ 低通滤波 |
| 日光灯嗡鸣 | 50Hz 正弦 + 100Hz/150Hz 谐波（幅度递减）+ 极轻随机噪声 |
| 风扇/空调 | 带通滤波白噪声（风扇=200-800Hz 中频抖动；空调=100-400Hz 稳定） |
| 夜风 | 低通粉噪 + 慢速幅度调制（LFO 0.1-0.3Hz） |
| 纸张/布料 | 短促高频噪声 burst（随机间隔） |

## 规格基线（硬规则）

| 项 | 要求 |
|---|---|
| 采样率 | 44.1kHz 或 48kHz，16bit 起 |
| 单条时长 | 整数秒；拟音点 0.5-3s；环境声 5-10s（可循环） |
| 响度 | 单资产 -20±3 LUFS（混音时再按层衰减）；环境垫底最终 -15dB 相对人声（sfx-layer 0.18） |
| 循环性 | 持续类（灯/风扇/空调）尾部做淡出便于 loop，标注可循环 |
| 命名 | `HN_声音_名称_Vxx_OK.wav` |

## 剧本静音/声场规则（用户硬要求）

- **静音段**：剧情节拍需要"环境音逐层淡出仅留呼吸+笔尖纸声"（如场九落笔段）——声音资产清单必须标注该段为静音设计，不铺底噪；
- 拟音点与 BGM 鼓点错开 ≥0.1s（沿用 sfx-layer 规则）；
- 群演不发声；电话/电视笑声等声源必须对应剧本在场物。

## 验证（交付前必做）

1. ffprobe：时长/采样率/声道（`ffprobe -v error -show_entries stream=codec_name,sample_rate,channels -of default=noprint_wrappers=1 x.wav`；无 ffmpeg 时用 Python wave 模块读帧数与采样率）；
2. 听感：单资产听一遍（AI 生成后试听），确认声源正确、无杂音爆音、材质符合年代（老式=有底噪/摩擦感，禁电子合成塑料感）；
3. 响度：AI 生成默认响度即可，混音阶段按 sfx-layer 分层；
4. 归档后回听验收：结合对应分镜镜号，声音与画面动作一一对应。

## 角色特质差异化（用户硬要求：每个角色声音各不相同）

**角色声音是一份长期契约**：同一角色跨镜/跨集复用同一音色锚点描述，不同角色之间必须可区分（听声辨人）。两步：

1. **建角色音色表**：每个角色一份锚点（年龄/性别/身份/音域/共鸣/语速/咬字/基准情绪/极端情绪下不变项），参考 `references/character-voices.md`（本项目 6 角色已建表）；
2. **生成/复用时绑定**：配音提示词在台词旁复写该角色音色锚点；角色关联拟音也带角色质感（例：老人手翻纸=迟缓摩擦感强、年轻手=轻快干净，钥匙声同角色同质感）。

**禁止**：全角色共用一套"标准女声/男声"；角色 A 的台词用角色 B 的音色描述；跨镜音色漂移。

## 顶尖声音设计方法论（2026-10-19 调研蒸馏，重做声音前必读）

调研结论浓缩在 `references/sound-design-mastery.md`，核心是"真实声学参数表 + 通用方法论"：

1. **真实声学参数表**：日光灯=100Hz 哼声主（工频 2 倍频）+42-48dB 极轻+漂移；午休铃=电磁铃钟罩共鸣 820Hz 拍频对+长余韵（非车铃短音）；脚步近远=滤波+混响比+瞬态（远=低通~900Hz+混响多+瞬态糊+音量-14dB，近=全频+紧拍回声）；电视=低通 800-1500Hz 陡降+低音量垫底；风扇=电机 100Hz 嗡+叶片通过频率周期调制；心跳=lub-dub 双搏 80→40Hz 扫频+click；夜风=粉/棕噪+0.03-0.2Hz 慢 LFO+树叶层。
2. **通用方法论**：距离=音量+滤波+混响+瞬态；声音床三层（rumble+hiss+rustle）；室内 room tone（decay 0.4-0.9s、低切 150Hz、send -18~-12dB）；慢 LFO 防 loop 感；机械声 Brownian 漂移+拍频对做"活"感；同声源随机变体；impact+transient+tail 分层。
3. **执行**：可程序化合成的用 `临时工具\sound_fix_*.py` 思路（纯标准库 wave/math/random，0 成本精确控参）；AI 生成后按上表后处理（低通/混响/音量）再归档。
