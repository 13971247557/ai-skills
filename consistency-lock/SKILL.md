# AI 视频一致性锁定 SOP（consistency-lock · 通用版）

> 核心：扩散模型每次生成没有共享状态，**纯文字锁不住跨镜头人物**；必须"参考图 + 元素绑定 + 首帧 + 首尾帧"硬锚。
> 本文件是**方法论**，可迁移到任何短片。每个项目把专属内容填进文末《项目锚点表模板》，另存为该项目的《总锚点表.md》。

## 零、生图前强制门禁（每次 image_gen / image_edit 前必跑，不过不出图）

**【最高硬规则】每次写提示词（无论出图还是出视频）前，必须先重新 Read 本 SKILL.md，按七槽骨架现场组 prompt；不许凭记忆直接写。写完在纸面上过一遍七槽是否齐全，缺槽不许调用生成工具。这是不可跳过的步骤。**

**【硬规则】每次写 prompt 前，必须先在脑内/纸面上过一遍七槽（机位/材质/家具/光线/纵深/风格/负面），并核对站位逻辑：室内商业主体（柜台/收银/操作台）永远在店内、人物站对侧、路人在门外人行道**沿街同向走过（平行门面、不是冲店门走）**、人物机位是站人行道看门面不是露天摊。七槽没填全、站位没核对，不许调用图工具。**锚点不是参考——是硬约束：掌柜/店主位置、柜台方向、主光源位置、门位置一旦锁定，只改需要变的元素，不许连店主一起重 roll；改街景就保留店主和柜台，只动门外。**

这是硬流程，不是"记得就做"。生图前先读本项目《总锚点表.md》，逐条打勾，任何一条没进 prompt 就不调用工具：

- [ ] **基调**：本片定的影调/氛围写进 prompt，并写反例词（如"不昏暗/不破旧/不阴森"），防跑味。
- [ ] **带参考图**：世界图（内景/外景/街景）用 image_edit 绑对应锚点，不让 AI 凭空重造一个场景。
- [ ] **人物身份块逐字**：本项目每个角色的发型/服装颜色/标志特征/可见范围，照抄不改。
- [ ] **道具块**：关键道具形状/颜色/材质/磨损写死（注意品类别错，如银饰≠玉饰）。
- [ ] **布景块**：门/柜台/招牌/关键道具的位置关系照定点图写。
- [ ] **灯光块逐字粘**：主光方向+补光+胶片感+景深+色调，每条都粘。
- [ ] **出图后回查**：对照锚点表逐张核，跑了就重出那一张，不带病进下一步。

## 零·研究门禁（生图前先查资料，凭依据不凭想象）

只要画的是**特定时代/真实场景/特定品类**（如宋代汴京商铺），生图前先做一次检索，把结论变成画面约束，不许凭空摆：

- [ ] **先搜再画**：用 general_search 查这个时代/场景的真实形制（建筑、服饰、器物、街道布局、相邻业态），引用可靠来源（博物馆、正史、专著）。
- [ ] **把结论写成视觉约束**：例如"小店=单层双开间、门脸朴素、伸竹檐；彩楼欢门是大酒楼自己门口、隔几间不压在本店后"——写进 prompt。
- [ ] **不发明历史**：拿不准的形制不自己编，宁可不画对，也不画错。
- [ ] **参考图落地**：搜到的关键视觉特征，落成锚点图后绑参考图再生。

## 零·补、画面零文字纪律（全程硬门禁，违反即废图）

AI 生图最爱在招牌、账册、布幌、灯笼上写乱码汉字/英文（"PAIN BLANT"之类）。纪律：

- **prompt 末尾固定挂负面词**：`no text, no letters, no characters, no words, no signage text, no watermark, no logo, no subtitle, no gibberish writing`。
- **招牌/账册/布幌/灯笼一律不写字**：招牌留白匾、账册留白线、布幌空白——要的字（"代守"、店名、促销、字幕）**全部后期叠印**，不靠 AI。
- **出图必查字**：逐张放大看有没有任何字符；一旦有乱码/假字/英文，这张作废重出，**不许带着乱码进下一步**。
- 可灵视频同理：prompt 写明 `no text on screen`，字幕后期加。

## 一、为什么会跑

- **没有共享状态**：每次生成独立，模型不记得上一镜。
- **首帧是命门**：去掉图生视频首帧，角色一致性从 7.99 掉到 0.55；i2v 比文生稳。
- **运动=漂移**：镜头甩越猛、动作越大，脸越跑。稳=小动作+首帧。
- **背景被当身份**：参考图背景杂乱，会被编码进"这人长啥样"。

## 二、四层方法（从弱到强叠加）

| 层 | 方法 | 适合 | 局限 |
|---|---|---|---|
| 1 | 文字身份块逐字复用 | 单镜、兜底 | 多镜必崩 |
| 2 | 参考图 + i2v 锁首帧 | 一镜内稳 | 切镜会跑 |
| 3 | **元素绑定（Bind Subject）** | 跨镜主角（主力） | 需先建元素 |
| 4 | 首尾帧串联 | 接戏转场咬合 | 需逐帧对接 |

> 叙事短片 = 层3+4打底，层2做每镜首帧，层1文字兜底。

## 二·补、漂移根因诊断（每次翻车先对号入座）

跨镜变脸/变装/变场景，99% 是这三条之一，不是模型不行：

- **A 无参考锚**：只给文字，模型每镜凭空重造 → 必须绑参考图做首帧。
- **B 单镜塞太多**：一镜里多个动作 + 多个运镜 + 多件新物 → 拆成一镜一动作、慢推/固定机位。
- **C 每镜不重复 lock block**：同一角色这镜写"黑色夹克"、下镜写"深色外套"——**换同义词=换人**。身份块必须逐字粘，一个字都不改。

**精修硬规则：**
- 角色表要 3–8 张多角度：正面 + 侧面 + 四分之三 + 全身 + 标志特征特写（如主角的胡茬、配角的老年斑）；只有正/侧不够，转背/转身必崩。
- 干净 setup 防闪：一个主体、一个主光源、干净背景、慢运镜；快切+反光物体+杂乱背景最易飘。
- 每镜先出静帧小样，核对脸/衣/道具/灯光过了，再用同一静帧做 i2v 动起来。

## 二·补2、同一场景多机位（换镜头不换房）提示词配方

跨镜场景漂移（长街里一间房、近景变成另一间房）的根因：换机位时没写死"这间房不能变的资产"，AI 当成重新设计。**正确是三句式，缺一不可：**

1. **锁死不变项**：先把建筑结构、门窗位置、招牌/横匾位置、家具摆放、材质、色调、光方向逐字写死，句尾钉一句 **"do NOT redesign the scene / 保持同一间，不重新设计"**。
2. **只换机位**：明确新镜头位置与高度，如"camera moves across the sidewalk to a closer view of THIS SAME shop"。
3. **透视对应**：合理透视、物体位置与参考图对应、不新增不删改结构。

**落地硬规则：**
- 建一个**场景身份块**（和人物身份块同级别）：把这一处场景的不可变特征逐字写一段，每次出该场景任何机位都整段粘。
- 多图绑定顺序：身份图先、场景/结构参考后、风格色调最后。
- 先出一张**俯视图/结构图**锁定空间，再从它派生各机位（俯视→长街→近景→内景），不要凭空拉近。
- seedream 编辑公式：`[目标区域]+[具体改动]+[保持不变约束]+[风格/光线/质量]`；"保持不变约束"必须含场景身份块。

## 三、六步 SOP

1. **建参考图集**：每主角 2–4 张（正面+侧面+服装/表情），背景纯白/灰抠干净，光线统一；配文字身份块。
2. **建元素绑定**：参考图传进可灵 Element Library，生成时勾 Bind Subject（最多绑3个：主角+关键道具+场景）。
3. **首帧锚定**：每镜用参考图当首帧 i2v；先出静帧小样核对脸/衣/道具，过了再动。
4. **首尾帧串联**：上镜末帧=下镜首帧；咬不上低 denoise≈0.25 贴合，或重抽换 seed。
5. **压运动**：一镜一个小动作；极端角度靠多角度参考图+绑定，不靠猛运镜。
6. **抽帧验收**：每镜抽 25%/50%/75% 三帧对照身份块查；跑了就带参考图重抽，不带病进合成。

## 三补、血泪教训：为什么每次都崩（反模式，坚决不犯）

1. **先冻参考包，再出图。** 人物脸/场景/平面图/道具没全部锁定前，不许拍镜头。脸一改，下游全部白做——别边定参考边出图。
2. **参考图扛几何，文字扛不动。** 柜台位置、人站哪侧、门在哪，要把俯视图/结构参考图喂进去，不是写一句"柜台在左中"。
3. **每张都强绑锁定参考。** 角色脸、关键道具（如银簪）每张图都带对应锁定 URL，不许从文字重新抽卡。
4. **一次过，不打地鼠。** 把脸/结构/道具/零文字/光线写进同一条 prompt、绑全套参考图一次生成；禁止擦完字再改脸、改完脸再改站位（每次重抽=新随机，修一处崩三处）。
5. **零文字逐图查。** 负面词逐图挂；出图先放大查招牌/画面里的字，见字即废。
6. **出图先核对再交付。** 对照锁定脸、锁定道具、平面结构逐项核，不达标不进下一张。

## 三补2、机位空间感（别拍成平照/护照照）
小店铺内景最容易拍成"正对后墙的证件照"。电影感五条，每条 prompt 至少满足两条：
1. **三层纵深**：前景一个虚焦物体（柜台角/门帘边/油灯/木柱）→ 中景主体 → 背景。镜头和主体之间必须有东西挡一下，不能空。
2. **斜拍墙角**：别正对一面墙；机位斜 30–45° 拍墙角，让两面墙 + 墙角出对角线，纵深才出来。
3. **框中框**：从红帘门、格扇窗、门洞之间往里拍，用建筑当画框。
4. **L 形布景斜拍**：同时带进两面墙（柜台一面、后架一面），不拍正面平墙。
5. **视线引导线**：柜台边、地面缝、灯杆斜线把眼睛带向主体。
- 反例：相机在屋子正中央、正对后墙、所有东西同一平面、没有前景遮挡 = 扁平照片。
- 出图先看：有没有前景虚化层？有没有对角线/墙角？没有就重拍。

## 三补3、平面→3D空间感六法（治"扁平证件照"）
一张平的画面变立体，靠这六招，出图前自检：
1. **分层**：前景（虚焦，离镜头最近）→ 中景（主体）→ 背景，三层不能在同一平面。
2. **前景遮挡**：镜头和主体之间放一个虚焦物体（帘角/柜台边/灯/柱/瓶），压一角就有纵深。
3. **斜拍墙角/L形布景**：机位斜 30–45°，同时带进两面墙和墙角，出对角线。
4. **框中框**：用门洞、窗、帘把主体框住，建筑本身当画框。
5. **引导线**：柜台边、地面缝、灯柱、墙脚线向主体汇聚（一点透视）。
6. **光做体积**：一束侧光切出亮面/暗面/投影，物体有受光、背光、落地影，不贴墙。
- 失败像：主体贴墙、无前景、无投影、四面平光、像证件照。

## 三补4、平面图纸→真实场景建模（一致性优先）
从平面结构图到可信 3D 空间，七步，每步都对回图纸：
1. **先定一个真实尺度锚**：门宽 80–90cm、柜台高约 1.1m、通道留 90cm；所有物体按这个比例缩放，不许忽大忽小。
2. **相机贴人眼高**：室内机位 1.4–1.6m 站立高度，35–50mm；禁止悬浮/吊顶俯视（那是示意图不是房间）。
3. **人站哪镜头放哪**：机位放在一个真人真会站的位置（门口、柜台前、过道），不悬空。
4. **对回图纸审计**：出图后数门洞/窗、追入口、核对柜台和后架位置；凡和平面图不一致的地方就是错，重出。
5. **材质统一**：全店一种木色/一种灯光语言，不东一块西一块像拼贴。
6. **走位要走得通**：按平面图的 A/B 走位，通道真能过人，箱子真能拖到柜台。
7. **俯视只用于自查**：dollhouse/俯视只用来核对布局，不当成片镜头。
- 一致性铁律：同一间店，任何机位的墙、门、柜台、货架位置必须和平面图对得上；换机位只换角度，不改结构。

## 三补5、场景 prompt 七槽骨架（调研蒸馏，照填）
专业结构 = **[主体/空间] + [风格] + [材质] + [光] + [机位] + [氛围] + [参数/负面]**，逐槽填具体词，不写形容词堆砌：
1. **机位槽（最先定）**：站哪+人眼高+焦段+角度。例："站门口内1.5m、35mm、偏左30°看墙角"。整屋用24–28mm墙角全景，细节用50–85mm。
2. **材质槽**：每种材料带表面处理。例："风化旧木板墙、灰石地、旧木柜台哑光、黄铜戥子氧化、靛蓝土布"。
3. **家具槽**：每件=位置+尺寸+旧化。例："厚面旧柜台横左中、高1.1m、右留90cm通道、外侧木座板；后墙四柱横板敞开架格"。
4. **光线槽**：光源+方向+软硬+时刻。例："门外暖橙夜灯从右侧照入、油灯暖黄补光、地面柔影"。禁止无来源顶光。
5. **纵深槽**：写清视线终点。例："前景柜台边虚化→柜台→后墙架格"。
6. **风格槽**：只选一种媒介，别混。例："写实电影剧照、胶片颗粒、浅景深"。
7. **负面槽**：无文字/水印/标志/铁架/发光体/阴森/畸形手脚。
- 反例："宋代商铺内景，暖光，电影感"——AI 必瞎编。
- 每次七槽套进同一条 prompt，绑全套参考图（场景+锁定脸+道具）。

## 三补6、制作顺序门禁（先剧本后图，顺序错必返工）
正确流水线，一步没做完不进下一步：
1. **故事定稿**：主线/人物弧光/逻辑锚点锁死。
2. **导演脚本/分镜**：每镜写死 机位+主动作+台词(含语气批注)+声音+渠道；台词按电影写对话，不要小说式留白。
3. **冻锚点包**：机位库+锁定脸+多角度+表情库+道具+灯光块+负面词，全部锁死，不再改。
4. **逐镜关键帧小样**：每镜选机位、套七槽 prompt、绑全套参考图，出静帧逐张审。
5. **可灵动态**：静帧确认后做 i2v，小动作慢推。
6. **后期**：配音/字幕/招牌字/BGM/尾板。
- 血泪：故事/脸还在改时就出图，后面全白做。台词、机位、渠道必须在分镜步一次定，不拖到出片。

## 三补7、表演与对话（电影不是小说）
- 台词要写语气批注（气声/迟疑/自嘲/收），不是只写字。
- 情绪戏用人物对话推进，不靠旁白念剧情；旁白只负责开场铺垫。
- 表情用微表情（眼神微动/嘴角轻挑），不演成话剧。
- 正脸大特写+台词必崩口型；对话戏给侧脸/背影/手部，台词后期配。
- 长镜头用在戏剧高点（动线长镜/情绪递接），其余正常切。

## 三补8、信息同步门禁（一改全改，防各文档打架）
每定一个新决策/新图/新设定，必须当场同步到三处，不然后期必对不上：
1. **分镜表**：镜头动作/机位/台词更新；
2. **总锚点表**：身份块/机位/道具/锁定帧 URL 更新；
3. **导演脚本**：对应镜的表演/语气更新。
- 规则：任何"改了 X"的动作，结束前 grep 一遍分镜+锚点+脚本里旧描述，统一改掉；镜号、年龄、道具、出场顺序最易打架，逐处核对。
- 例：穿越光从一道硬闪电改成"外景飞光→正常等客→光入体"三拍，就要同时改分镜 S1、锚点 S1 三帧、脚本 S1 表演。

## 四、红线
- ❌ 一镜堆多个运镜。
- ❌ 纯文字锁跨镜人物。
- ❌ 正脸大特写+长台词（口型微表情必崩；改侧脸/背影/手部或旁白）。
- ❌ 不先出静帧就大动作生成。
- ❌ 画面内写字（AI 必乱码，一律后期叠印）。

## 五、易漏的其他维度

- **场景**：先出一张主宽景喂给该场景每条镜；写死门/柜台/货架/主光；先宽景后特写。
- **灯光**：定一个主光方向做成灯光块逐字粘；调戏剧化只改反差，不移光源。
- **道具**：建追踪表（形状/颜色/材质/磨损）；同角度手-道具特写抽 3 条选最稳。
- **轴线/参数**：正反打守 180 度；全片锁焦段景深。
- **多人同框**：Master Plate，两角度从同一张主宽景派生；站位写进每镜；视线对上。
- **转场**：动作接点（上镜别把动作做完）；首尾帧硬接；留 1–2 秒重叠叠化。
- **穿帮兜底**：局部错就蒙版重绘那块，别整段重抽省积分。
- **负面词后缀**：人物出镜挂"不要文字/水印/字幕，面部畸变，换脸，手指过多粘连，手部扭曲，多余肢体，缺少手脚，肢体畸形，手指数量错误，抖动，闪烁，突然打光变化，晃镜，模糊，低质量"；
- **人群/路人质量**：路人走路自然放松、体态正常、表情平和，**不要夸张亢奋、脖子僵硬前倾、瞪眼张嘴的"甲亢"式神态**；所有人物四肢齐全、双手十指正常、不多手不少手不连体。
